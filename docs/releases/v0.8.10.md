# Pi Desktop v0.8.10

一处交互口径的调整：**打开项目就是一次新对话**，不再自动接管上一次聊的内容。

## 打开项目不再自动续上一次对话

以前每次启动应用（或点开一个项目），会话进程会把「最近一个非空会话」切进来 —— 本意是「重开应用接着上次聊」，实际效果是每次打开软件都直接看到上一轮对话，想开个新话题还得先自己按一次「新会话」。

现在的规则：

- **打开应用 / 点项目** → 新对话，界面上是欢迎页。想接着聊，从左侧会话列表里点那一条就行。
- **崩溃、启动超时后重试同一个项目** → 仍然是接着原来的会话，不会因为重试把上下文丢掉。
- 侧边栏点会话、`restart`、导入会话、隔离工作区「关联已有对话」 —— 行为不变，都是显式恢复。

历史会话不会被删除，仍然完整地留在会话列表里。
