# Pi Desktop v0.5.0

这一版主要在「顺手」上：设置页整体重做（自绘下拉、可搜索、Pi CLI / Pi Desktop 独立成页）、窗口按钮自己画（悬停终于有反馈）、待发送队列能拖着调整顺序。另外修了几个一直碍事的问题：右上角窗口按钮的配色总慢半拍、图片点开放大没反应、压缩上下文总在 30 秒时报失败。

## 待发送队列：拖着排、看得懂

- **拖拽排序**：整张排队卡片可以直接拖（左侧有把手），拖到卡片上/下半区决定插到它前面还是后面，蓝色插入线提示落点。
- **界面顺序就是发送顺序**：Pi 有两条队列（引导 = 立刻插入当前回合，排队 = 本轮结束后发），所以列表永远「引导在前、排队在后」。把排队的拖到引导组里，它就**顺手变成引导**——不会出现「排在后面的反而先发」这种看不懂的情况。
- **投递方式改成下拉**：原来的小标签点一下翻面，很容易误改发送时机；现在是「引导 ▾ / 排队 ▾」，两种选择各自的时机都写在选项里。
- 列表按组加了一句说明：「引导 · 立刻插入当前回合」「排队 · 本轮结束后按顺序发送」。

## 设置页

- **搜索能搜到设置项**：以前只能搜页名，敲「深色」「字体」「快捷键」一个结果都没有；现在每页登记关键字，命中词会标出来，`↑↓` 选择、`Enter` 打开，`Esc` 先收搜索再关窗口，`Ctrl K` 聚焦搜索。
- **Pi CLI 与 Pi Desktop 提升为一级分区**：这两个原本挤在「环境与快捷键」里，一个更新命令行工具、一个更新桌面应用，很容易搞混；现在各自一页，互不干扰。
- **一级分区改名换图标**：「能力」→「扩展」，「桌面」→「系统」，Pi Desktop 换成手绘的窗口字形。
- **下拉框全部自绘**：原生 `<select>` 的弹出层是系统画的，深色主题下会弹出一块浅色系统菜单，和设置页完全割裂；现在 15 处下拉都换成跟随主题的自绘控件（键盘、ARIA 都在）。
- **主题缩略图**：深色 = 纯黑、浅色 = 纯白、跟随系统 = 左黑右白。
- 细节：底部显示「已改动 N 项」、换页后滚动位置归零、页头滚动时补阴影、二级 tab 支持 `←` `→`。

## 窗口与浮层

- **窗口按钮自己画**：系统的 `titleBarOverlay` 按钮悬停没有任何反馈、配色还要靠 IPC 通知，永远慢一帧。现在最小化 / 最大化 / 关闭自绘：悬停高亮、按下更深、关闭按钮悬停变系统红，最大化后图标变「向下还原」，双击标题栏也能最大化。
- **遮罩不再盖住标题栏**：从标题栏下方开始，原生按钮区不需要跟着压暗，也就没有「右上角慢一步」这回事了。
- **修好图片放大**：点图片没反应——放大层用了只定义在 `.shell` 上的 `--titlebar-h`，Teleport 到 body 之后读到空值，整条 `inset` 失效，缩成了视口外的 64×64 小方块。

## 修复

- **压缩上下文不再 30 秒报失败**：上游 RPC 客户端给每条命令只留 30 秒，而 `compact` 要调模型总结整段对话；现在超时被当成「还没回」，改为等 `compaction_end`（上限 10 分钟）。
- 设置页「记录内容」不再被挤成一字一行。
- 执行记录的总时长恢复显示（回放会话时间戳挤在同一毫秒时也有值）。

## 兼容性

- 界面图标统一换成 IBM Carbon（Apache-2.0），已补进 `THIRD-PARTY-NOTICES.md`。
- 设置项与旧版本兼容，升级后配置保留。
