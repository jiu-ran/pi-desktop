# Pi Desktop v0.2.9

设置里的 Pi 信息合并成一张卡：状态、路径、更新原来分成两张，内容还重复。

## 改进

- **「本机 Pi CLI」与「Pi CLI 更新」合并为一张卡**，顺序也理顺了：

  1. **Pi Coding Agent CLI** —— `已连接 · 当前 1.4.0 · 最新 1.4.0`，右侧状态标签（已是最新 / 有更新 / 检查中 / 未安装）
  2. **Pi 路径** —— 自动识别 / 手动指定、复制、修改
  3. **检查并更新 Pi** —— `pi update` / `update --all` 下拉 + 检查更新 + 立即更新
  4. **Pi 自动更新** —— 开关
  5. **上次更新结果** —— 仅在有过更新时显示
  6. **当前活动项目目录** —— 会话线程数、运行中数量、重启当前会话进程

  以前「已连接 · 版本」和「当前 · 最新」分处两张卡的顶部，说的是同一件事；现在合成一行，重复的「版本状态」整行去掉。

## 校验

- ✅ `settings.electron.mjs` 新增断言：环境页不再有「Pi CLI 更新」独立卡；合并后的卡必须同时包含 Pi 状态、路径、检查并更新、自动更新、当前项目五项
- ✅ `npm run check` 全绿；Electron 冒烟 PASS（含环境页截图核对）
