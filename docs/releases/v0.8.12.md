# Pi Desktop v0.8.12

一处手感修正：**往上翻历史时，不再需要「先下滑、再上滑」才继续加载**。

## 上滑加载不再卡住

之前滚到顶、加载了一页（约 8 条）之后就不动了，得先往下滑一小段再往上滑，才会加载下一页。三个原因叠在一起：

- **节流把最后一次上滑吞了**：为了不连点，加载有 500ms 节流。你一口气滑到顶时，第一页往往正好在这个窗口里加载完，剩下的滚动事件全被丢弃；画面不再滚动，也就不会再有新事件 —— 彻底卡住。现在被挡下的那次会排到节流窗口末尾补一发。
- **「是否还在顶部」用 `scrollTop` 判断**：插页后为了保持视觉位置，会把 `scrollTop` 往下挪一大截（可能上千像素），于是刚加载完就被判成「他已经往下看了」，自动续载立刻收手。现在改用**滚轮方向**记意图：往上滚 = 想读更早的内容，往下滚（或点「回到最新」）才收手。
- **内容撑不满窗口时根本滚不动**：短会话 / 大窗口下没有滚动条，也产生不了滚动事件。现在换来会话或内容变化后会主动补页，直到撑出滚动条或没有更早的消息。

节奏上有刹车：

- 加载完一页、人还想往上读 → 自动接着补下一页；
- 单次手势最多自动续载 **6 页**，手停下后最多再补 2 页就收手，不会一路把几万条历史拉到底；
- 离开顶部、点「回到最新」、切换会话都会把额度清零。
