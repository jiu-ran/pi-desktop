# Pi Desktop v0.4.1

执行记录终于不再刷屏：**按真实顺序**列步骤，连续同类步骤自动合并成一行，展开就直接看到内容，不再套第二层标题。另外：渲染结果与源码可以同屏、代码块与表格一键复制、对话强调色能和界面强调色分开设置。

## 执行记录：时间线 + 降噪

v0.4.0 把执行记录按「一次请求」聚合成一组，但组内还是按类别归并（思考挤一起、命令挤一起），看不出「先跑测试 → 报错 → 改代码」的节奏。这一版彻底改成时间线：

- **严格按真实发生顺序**列出每一步：思考、运行、读取、改动混排，不再分类归并。
- **连续同类步骤合并成一行**：截图里那种连着 4 条 `cat > scripts/checks/_apN.cjs` 现在只占一行，
  显示成 `cat > scripts/checks/_apN{1..4}.cjs`，右侧标 `×4`，点开逐条看。
  - 只有「同工具 + 只差中间一小段」才合并；三条互不相同的命令不会被硬凑。
  - 区间压缩只在**步长 1** 时生效（`0..17`），`1|3|5` 这种等差不会被写成 `1..5`。
  - 连续 ≥ 3 步才合并（两步不值得多一次点击）；设置 → 对话可关掉，关掉只剩下面的淡化。
- **相同前后缀淡化**：不合并时，相邻两步相同的 `npm run check --` 淡成灰色，只有变化的 `1`、`2` 保持正文亮度。
- **展开即见内容**：步骤行就是「动作 + 参数」，点开直接是终端输出 / 代码差异 / 思考正文——
  不再出现「运行」下面再套一个「运行」标题，也没有「已思考」这层壳。
- **改动行显示 `+N −N`**：卡片头部不再画，增删行数直接落在行尾；多次改动合并时累加。
- 去掉了步骤序号与圆点，只按顺序排下来；长命令 / 长输出限宽滚动，不再把页面撑宽。
- 失败步骤保持红色标记，搜索命中时合并行与逐条自动展开。

## 渲染与源码同屏

点「源码」不再顶掉渲染结果，而是在**下方**挂一个源码面板，两边同时可见（面板打开时上方只读，`Esc` 或再点收起，改面板会写回文档）。代码块和表格都加了**复制按钮**：代码块复制正文（不含 ``` 围栏），表格复制整块 markdown（含表头与 `| --- |`）。

## 强调色可分开设置

- 「对话强调色」可以**跟随**界面强调色，也可以单独指定——两者独立，改界面色不会带着对话文字一起变色。
- 界面强调色与对话强调色都支持**任意取色**（系统取色器），不再局限 8 个预设。

## 排队消息与气泡

- **编辑排队消息不再把图片路径复制一份**：之前把展示用的 `[文件: …]` 标签写回了提示词，保存后图片路径出现两份；现在提示词拆成「块」与「文字」，编辑只改文字。
- 编辑框里能看到待发送的附件，支持 `Ctrl+V` 直接粘贴新图片。
- 用户气泡里的附件顺序改成**图片 → 文件 → 文字**，和输入框一致（之前文字在上）。

## 其它

- 右侧大纲不再显示「第 N 轮」，只留用户消息本身（悬停提示也一样）。
- 执行记录里「思考」步骤展开后，行内摘要自动隐藏，同一段话不再重复两遍。

## 校验

- `npm run check` 全绿，新增 `timeline-rows.check.ts`（前缀切分 / 合并条件 / 区间压缩 / 阈值与打断 / 状态传递 / 增删累加）。
- `npm run build` 通过；Electron 冒烟 21 步 PASS。
- `activity.electron` 覆盖：22 步压成 3 行（`×18`、`×3`、单步）、展开合并行出 18 条、点某条只挂一张卡、
  关掉合并回到 22 行且出现淡化片段、无序号 / 无圆点 / 无重复头部 / 无横向溢出、改动行文字是 `+2` 与 `−1`。
- 反向验证（把关键判定改回旧行为，确认断言会红）：
  - 合并判定改回不合并 → 直接报「应压成 3 行，实际 22」；
  - `queueDraftText` 改回 `stripQueueMarkers` → 报「`[文件: C:\a\b.txt]\n看看这个` vs `看看这个`」；
  - 气泡顺序改回文字在上 → 报「附件必须在文字上方」；
  - 大纲加回「第 N 轮」→ 报「不该出现「第 N 轮」」。
