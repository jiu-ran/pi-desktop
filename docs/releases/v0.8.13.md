# Pi Desktop v0.8.13

围绕「新会话用什么模型、什么思考程度」的一整轮整理：以前没有入口、设了不生效、选项和模型对不上，现在都在输入框里一次搞定。

## 默认模型与默认思考程度

设置 → 对话 新增「新会话默认模型与思考等级」，写入 Pi 自己的 `defaultProvider` / `defaultModel` / `defaultThinkingLevel`（`settings.json`），因此终端里的 `pi` 也认同一份 —— 不会出现「桌面端选了 A、命令行还是 B」。

- **写入位置**可选全局（所有项目）或当前项目（`.pi/settings.json`，沿用信任规则）。
- **「跟随 Pi 默认」= 删掉那两个键**，不是写空串。
- 顺带修掉旧问题：原来那行「默认思考深度」只写 localStorage，**新会话根本不会用它**。

## 输入框里就能设，不用跳设置页

底栏原本是两个下拉（模型、思考），现在合并成一个 `模型名 · 思考` 触发器：

- 上半区选模型（可筛选，当前默认模型行内带 `默认` 徽标）；
- 中间是「思考程度」按钮组，**只列这个模型真正支持的档位**，切换模型后即时刷新，面板不关；
- 当前新会话默认的那一档，直接在按钮里带一个小 `默认` 徽标；
- 底部一次把「当前模型 + 当前思考」写成新会话默认，点击后保存并自动收起面板。

## 思考等级跟着模型能力走

不同的模型支持的档位并不一样：不支持推理的模型只有「关闭」，部分模型没有 xhigh / max（你机器上的 deepseek 就只支持 low / high / max）。现在按 Pi 内部的规则过滤：

- 不支持推理 → 只有「关闭」；
- 档位映射成 `null` → 该档不出现；
- `xhigh` / `max` → 只有提供方显式支持才出现；
- 已保存但不支持的等级会被收敛到最近的可用档，不会「选了没反应」。

切换模型后还会把 Pi 自动钳制过的等级同步回界面，按钮和实际状态不会脱节。

## 显示不再被截断

- 模型按钮最大宽度 180px → 280px，「DeepSeek V4.1 Flash」不再变成「DeepSeek V4.1 Fl…」；
- 合并后的触发器更宽（最多 360px），窄舞台只把思考文字收成图标，不再把整段压成省略号；
- 下拉菜单从 `min-width: 200px` 改成按内容撑开（最小 280 / 最大 420），列表里的模型名 + 徽标 + 提供方一次展开；
- 底部动作文案去掉重复的 hint，只留一句说清状态与动作的话。
