# Pi Desktop v0.9.3

这一版主要是两件事：**Windows 安装向导跟着系统说中文**，以及一整批**界面动效**。另外修了会话行悬停时状态点被删除按钮盖住的小问题，README 也精简了一轮。

## Windows 安装程序

以前安装向导只有英文。原因是 MyGo 用「应用声明的语言」生成 NSIS 的多语言界面，而我们没有声明任何语言，默认就按英文走。

现在 `locales/` 下有 `zh-Hans.json` 与 `en.json`，配置里的源语言是 `zh-Hans`：

- 中文系统的安装向导是中文（「安装(I)」「取消(C)」「选择安装位置」…）
- 英文系统仍是英文
- 文件属性表与 MyGo 自带控件（菜单、对话框）也跟着系统语言走

顺带把桌面快捷方式的描述一起修了。以前鼠标停在图标上会看到「（Electron + Vue 3 + TypeScript）」——那不是 README 或代码里的文案，而是**旧安装器写进 `.lnk` 的描述**，Windows 不会自动更新它。新版安装会用 `mygo.appDescription`（「基于本机 Pi Agent CLI 的跨平台桌面客户端」）。如果看到旧文案，重新装一次即可。

## 界面动效

### 主题切换：圆形揭示

点标题栏的月亮 / 太阳，新主题会从点击的位置以一个圆扩散开来（View Transitions API，460ms）。外观设置里点不同的 wash 也是同一套动画。浏览器不支持、连续点击或关闭动效时，退回直接切换，不会卡住。

### 对话

- **新内容从下方浮入**：只让最新的 1–2 块做淡入上浮，上滑补齐的历史仍从上方落下（两条方向相反的动画各管一边）。
- **切换会话整屏淡入**：不再硬切。
- **执行记录展开逐行浮起**：最多错开 6 行，像把记录一层层铺开。
- **进行中的记录有柔光**：折叠头每 2.8 秒扫过一条淡淡的强调色光带，替代「只能盯转圈图标」的提示。

### 等待连接

「正在连接 Pi…」从一个小转圈换成了品牌 π 徽标，它每 2.4 秒呼吸一次，下面配一行状态字。

### 发送

点发送成功后，一颗带辉光的光点从发送按钮飞向对话区底部。发送失败不播。

### 其它

- 终端面板每次展开上一次滑动；右侧扩展工具切换时内容淡入；侧栏会话行悬停轻微右移。
- 动效时长与缓动收成 `--motion-fast` / `--motion` / `--motion-slow` 与 `--ease-out`，以后调整手感只改这几个变量。
- **系统「减少动态效果」现在和外观设置里的「关闭界面动效」走同一个开关**（动画与过渡压到 0.001ms、平滑滚动关掉），不再需要每个组件各写一遍媒体查询。

## 修复

- **会话行悬停时状态点被删除按钮压住**：悬停时时间和徽标本来就会隐藏给删除按钮让位，唯独末尾那个状态点没跟着隐藏。现在三者一起让位。

## 校验

- `npm run check`：57 个界面 / 纯逻辑检查 + 3 个静态分析（`tsc` / `vue-tsc` / 脚本语法）全部通过，`go vet ./...` 与 `go test ./...` 通过。
- 宿主冒烟（host / PTY / 一次性命令 / 真实 Pi prompt / 界面 / 设置 / Git 与 worktree）全过；退出 3 秒后无残留 `node` 进程。
- 安装向导语言用 UI Automation 实测：标题「Pi Desktop 安装」，按钮「安装(I)」「取消(C)」。
- 动效用真机 DOM 探针验过：`startViewTransition` 可用，五条新动画规则全部解析，进行中的组头计算值为 `activity-sheen / 2.8s`。

## 已知限制

- 安装包仍未签名，macOS 首次打开需要在「隐私与安全性」里放行。
- 大会话（100 MB 以上）首次打开可能超过 25 秒的启动超时，之后会单独处理（延迟加载或放宽超时）。
- 主题揭示依赖 View Transitions API：WebView2（Chromium）支持；若某个平台的 WebView 不支持，则自动退回直接切换。
