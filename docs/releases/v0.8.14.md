# Pi Desktop v0.8.14

这一版修的是 `.md` 实时预览里两个「点了没反应 / 点了跑偏」的手感问题，另外把提交时的回归检查从 87 秒压到 33 秒。

## 代码块点进去不再变白

以前在预览里点代码块想改一行，整块彩色高亮会瞬间变成一片白色等宽文字，光标还会弹回开头。

原因是点击时把 Shiki 生成的高亮标记整段清掉了（直接写回纯文本）。现在点进去是**保持原样高亮**、光标正好落在点击位置；改字的过程中高亮也跟着刷新，光标不会被拽走（中文输入法组合期间不打断）。

## 点某一行不再落到下面几行

文档里出现分割线、代码块或表格之后，越往下点越不准 —— 点「第一部分」的标题，光标落到下面第 4 行；键盘上下键也会一次跳好几行。

原因是 CodeMirror 测量块级组件的实际高度时不含 CSS `margin`，而这些块把上下间距写在了 `margin` 上：每条 `---` 让内部坐标偏移约 32px、每个代码块约 14px、每张表约 17px。十几个块之后累计偏差上百像素，点击与键盘反查坐标就都错了。

现在这些间距改用 `padding`（`margin: 0`），块高度测量与真实布局一致，点击精确命中、上下键逐行移动。顺带修掉光标在别处移动时整块代码被清空重画导致的闪动。

## 工程：提交时的回归检查更快更省事

- `npm run check` 从一条 80 多段的串行命令链改成自动发现 + 并行调度：全量 **87 秒 → 33 秒**。
- 新增 `npm run check:changed`：按改动的文件挑相关检查，只动界面/样式时约 4 秒。
- 隔离工作区的 Git 场景拆成独立检查，与其余检查并行跑。
- 检查共用的断言、临时目录、假 localStorage 收进 `scripts/checks/support/harness.ts`，并删掉 5 个没人再跑的手工探针与 87 行纯报名字的日志。

断言与覆盖范围没有减少，只是不再重复抄写。
