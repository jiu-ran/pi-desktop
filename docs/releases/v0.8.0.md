# Pi Desktop v0.8.0

支持完整的 Git Worktree（隔离工作区）配置创建与会话分叉；优化顶栏与侧边栏的 Git 交互；修复退格自指递归循环与 Node.js 22 启动警告。

## Git Worktree 隔离工作区

在不污染当前工作区与未提交代码的前提下，为独立任务或排查 Bug 开辟全新的物理工作目录：

- **分支策略与名称**：支持新建分支（自定义分支名，自动前缀 `pi/`，单向 slug 联动防冲突）或检出已有本地/远程分支（自动建立追踪，过滤已占用分支）。
- **起点阶段与合并目标**：支持基于本地分支、远程跟踪分支或具体提交（Commit Hash / Tag）分叉，并支持显式绑定合并回的目标分支（Base Branch），方便后续一键 Rebase / Squash 合并闭环。
- **物理存放位置**：默认存放于受控目录 `worktrees/<repoKey>-<slug>`，支持系统目录选择器自定义任意磁盘路径。
- **对话上下文与初始任务**：创建 Worktree 时可选择不加载历史对话（干净空白对话）、作为 `@引用对话` 上下文注入（推荐，结构化摘要，省 Token 且无旧绝对路径污染）、或完整克隆 `.jsonl` 对话历史；支持预填初始需求草稿并选择创建后立即发送。

## 入口与交互优化

- **顶栏与侧边栏去重**：移除顶栏与项目列表中重复冗余的 Git 图标，标题栏与项目行均保留单一分支徽标；点击顶栏分支名直接切换右侧「Git 版本控制面板」。
- **输入框工具栏**：Worktree 快捷按钮统一为标准的 26×26px 图标按钮，保证在小屏或分屏模式下底栏工具与发送按钮永远保持单行排版，彻底解决文字溢出截断为 `Workt` 的问题。

## 修复

- **任务标识退格递归循环**：修复当清空「任务标识」时因反向自指导致的 `pi/pi-pi-pi-...` 字符串无限拼接递归死循环，改为严格的单向数据流与优雅的占位提示回退。
- **Node.js 22 弃用警告**：修复主进程 `runCommand` 调用时触发的 `[DEP0190] DeprecationWarning: Passing args to a child process with shell option true` 警告。
- **工作区连接池健壮性**：修复多工作区并发调度与切换时的路径归一化解析与异常清理。
