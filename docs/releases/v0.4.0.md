# Pi Desktop v0.4.0

`.md` 预览换成真正的**实时预览**：文档本身就是编辑器，光标停在哪一行，哪一行才露出 `**`、`#`、反引号这类标记。表格和代码块点进去就地改，不再翻出源码；对话里的执行记录按「一次请求」聚合；自动更新默认开启。

## `.md` 实时预览（CodeMirror 6）

v0.3.x 的「块级混合预览」是把渲染结果切成块、点哪块换成编辑框，块与渲染节点必须严格对齐，对不上就整篇退化成纯预览。现在换成 Obsidian / Typora 的做法——**真正的语法高亮编辑器 + 行级标记收放**：

- 标记只在**光标所在的那一行**显示，其余行渲染成最终样子（加粗 650、行内代码等宽、链接只留文字）。
- 无序列表 `-` 换成圆点，有序列表保留淡色序号，setext 标题下划线保留淡色（收起会留下空行）。
- 图片：相对路径按文件所在目录解析 → 工作区相对路径 → 读成 data URL 内联显示；读不出来就画虚线占位，最大高度 520px。
- 代码块用 shiki 高亮（复用会话里的那套主题），切换深浅主题会重建。
- **Ctrl + 点击链接**：外部链接交给系统浏览器（走既有的白名单），`#锚点` 滚到同名标题，工作区里的相对路径交给文件插件打开。
- 退役旧的块级实现（`MarkdownEditable.vue`、`markdown-blocks.ts` 及其检查）。

## 表格 / 代码块就地编辑

点表格单元格、点代码块正文都不再显示源码：

- **表格**：每个单元格都可以直接改，`Tab` / `Shift+Tab` / `Enter` 换格；改完整张表重新序列化写回（列宽自动对齐），单元格里的 `\|` 不会被当成分隔符。单元格里的行内语法（**加粗**、`` `代码` ``、链接、~~删除线~~）会渲染出来，聚焦时露源码、失焦回到渲染结果。
- **代码块**：正文可以直接改，失焦后重新高亮。
- 两者右上角都有「源码」按钮；进了源码态按 `Esc` 或点「渲染」回到渲染结果。

## 执行记录按「一次请求」聚合

一次任务里有几十步工具调用时，原来会摊成 47 行。现在按「一次用户请求」分组：

- 组头一句话摘要：`执行了 N 步 · 改 N 个文件 · N 条命令 · 读 N 个文件 · 思考 N 段 · N 处失败`，加耗时（< 1s 不显示）。
- 真实会话实测 **47 行 → 15 行**。设置 → 对话里可以选**分组（默认）/ 紧凑 / 展开**三档；`Ctrl+Shift+E` 全部展开或收起。
- 失败判定只看最后一个已结算的工具——中途失败后重试成功不算失败。

## 强调色、自动更新与其它

- **强调跟随强调色**：对话和文件预览里的行内代码不再固定橙色 `--code`，改用你选的 `--accent`（配同色淡底）。
- **自动更新默认开启**：启动检查完查到新版本就自动下载并校验 SHA-256，只需要点一次「安装并重启」；之前打开开关也会立即补下载。检查失败时把原因（限流 / 断网）显示在版本号下面。
- **弹窗时压暗原生窗口按钮**：右上角最小化 / 最大化 / 关闭是 Windows 画的，盖不住遮罩；现在遮罩出现时把 `titleBarOverlay` 一起压暗（与遮罩同样的 0.45 黑），消失恢复。
- **悬停提示**：停留 700ms 才弹（指针扫过不再乱弹），收起缓冲 180ms，相邻元素切换仍然即时。

## 校验

- `npm run check` 全绿（新增 `live-preview` / `relative-path` / `activity-turns` / `markdown-block-edit` / `inline-markdown` / `update-auto` 六个检查文件）。
- Electron 冒烟 21 步 PASS，包含：实时预览的标记收放与版式、图片内联、Ctrl+点击链接、表格单元格与代码块就地编辑、执行记录分组、自动更新的调用链、窗口按钮压暗。
- 反向验证（把关键判定改回旧行为，确认断言会红）：
  - 标记收放判定改错 → 直接报「块级判定失败」；
  - 单元格改回纯文本 → 报「单元格不对：`["1","2","**配色模式**","跟随 \`--accent\` 切换"]`」；
  - 设置页改回直接查更新 → 报「手动检查更新后要自动下载，实际调用 `["check"]`」。
- 只打开 `.md` 不动光标不会写盘（`dirty: false`、磁盘 mtime 不变）。
