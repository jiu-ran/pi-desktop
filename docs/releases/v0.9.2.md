# Pi Desktop v0.9.2

**工具开关改成 Pi 官方推荐的增量写法；对话配色、执行记录的折叠与收起也一并重做。**

覆盖安装即可，0.9.1 的自动更新可以直接升到这一版。

## 工具开关：改成 `+name` / `-name`

以前打开一个默认没有的工具，桌面端会把**完整清单**写进 `defaultTools`：

```jsonc
// 打开 grep 后（旧行为）
{ "defaultTools": ["read", "bash", "edit", "write", "grep"] }
```

这等于把 Pi 当时的默认值固化下来——以后 Pi 调整默认工具集合，你的配置不会跟着走。现在改成官方推荐的增量写法：

| 操作 | 现在写入 |
|---|---|
| 打开默认没有的工具 | `["+grep"]` |
| 关掉默认有的工具 | `["-bash"]` |
| 开关回到默认状态 | **删掉 `defaultTools` 键**（跟随 Pi 默认） |
| 全部关掉 | `[]`（Pi 里表示一个都不启用） |
| 项目级开关 | 只记与全局的差异，例如 `["-grep"]` |

旧版写下的完整清单会在下一次点开关时自动重写成等价的 `+/-` 写法。起 Pi 时的 `--tools` 参数不变，仍由桌面端翻译成 `+read,+bash,…`。

## 对话配色

- **行内代码**不再直接染成「强调色」：以前浅色主题里一屏出现几十个暖色小方块，和冷色玻璃底撞色。现在改成中性淡底 + 正文色，强调色留给链接与真正的强调文字。阅读视图与编辑器（`.cm-md-inlinecode`）一起调整。
- **表格**只保留一层细线，表头改用中性淡底，不再叠出蓝紫色网格。

## 执行记录（思考 / 工具调用分组）

- **不再吸顶**：组头以前是 `position: sticky` + 半透明模糊，滚动时会盖住内容，还要额外处理「吸住了没有」。现在它就是一行普通文字，随内容滚动，hover 才出现底色；展开区也去掉了左侧竖线，只保留缩进。
- **新增悬浮「收起」**：组头滚出视野、记录还在一路延伸时，聊天区右下角浮出一个「收起」按钮，点它不必滚回组头。它固定在「回到底部」按钮上方 56px，两者不重叠；只在「组头看不见、组尾也没到」时出现。
- **收起后的落点固定**：收起时把这条记录的折叠头送到滚动区顶部（140ms 缓动，遵守系统的「减少动态效果」），视线落在刚收起的那条记录上，再展开的开关就在眼前。

## 输入框右键菜单

以前右键输入框弹的是 WebView 的原生菜单（Emoji、Writing direction、More tools 等），样式和整窗的玻璃视觉对不上，项也用不上。现在换成应用自己的菜单：**撤销 / 重做 / 剪切 / 复制 / 粘贴 / 全选**，带快捷键提示，没有选区时剪切与复制置灰；粘贴通过宿主读取剪贴板，读不到时会提示用 Ctrl+V。

## 会话标题

- 引用另一个会话开的对话，标题优先用你**在引用块后面写的内容**；只有纯引用、没写内容时才显示「原会话名（引用）」。标题后面还会带一个「引用」小标，悬停显示被引用的会话名。
- 列表里的会话标题相对项目名缩进一格，层级更清楚。

## 已知限制

- Windows 依赖系统 WebView2（Windows 11 自带；Windows 10 若缺失需安装 Evergreen Runtime）。
- macOS 安装包未签名 / 未公证，首次打开需要在「系统设置 → 隐私与安全性」允许；Windows 未做代码签名，SmartScreen 可能提示未知发布者。
- Linux 使用 `tar.gz` 内的 `install.sh` 安装到 `~/.local`，或使用 `deb` / `rpm`；桌面环境需要 WebKitGTK 4.1。
- 终端依赖本机已安装的 CLI 与 shell，应用不会代为安装、登录或配置。
- 文本文件读取 / 保存上限 20 MB，超过 2 MB 以只读大文件模式打开。

## 校验

- 下载 `SHA256SUMS.txt`，与本地文件比对：`sha256sum -c SHA256SUMS.txt`（Windows 可用 `certutil -hashfile <文件> SHA256` 手工对照）。
- 工具开关验证：打开 `grep` 后看 `~/.pi/agent/settings.json`，应只有 `"defaultTools": ["+grep"]`；再关掉它，键应整个消失。
- 执行记录验证：展开一段长记录、滚到中间，右下角应出现「收起」；点击后停在折叠头上，且与「回到底部」按钮不重叠。
