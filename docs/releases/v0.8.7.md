# Pi Desktop v0.8.7

三件事：**能自己选走哪种网络**、**更新失败的提示说人话**、**隔离工作区的命名重做**。

## 出网方式（设置 → Pi Desktop → 网络）

- 四个选项：**自动**（有 `HTTP(S)_PROXY` 就沿用，否则跟随系统）/ **系统代理** / **直连** / **自定义地址**（如 `127.0.0.1:7890`，可省略 `http://`，支持 socks）。
- 一次管两条路径：
  - 应用自身（检查更新、下载安装包）→ Electron 的 session 代理；
  - Pi（模型请求、MCP、`pi update`）→ 子进程的 `HTTP(S)_PROXY` 环境变量。
- 设置页会显示**当前实际走向**（「系统代理：http://127.0.0.1:7890」/「当前直连」），并可用「重启空闲会话」让已经在跑的会话换上新规则。

> 为什么需要这个：Pi 用 undici 的 `EnvHttpProxyAgent`，**只认环境变量**，系统代理设置它看不见 —— 这就是之前在图形界面里 `pi update` 直接超时的原因。

## 更新失败的提示

`pi update` 失败时不再把四行英文原文甩进提示条，而是归类成一句中文：

- 网络超时 → 「无法从网络获取 Pi 最新版本（检查网络或代理后重试；扩展包这次没有更新）」
- 权限问题 → 「没有权限写入 Pi 的安装目录（换有权限的账号…）」
- 认不出 → 取最后一行、去掉 `Error:` 前缀、截断 120 字

完整输出仍可在设置页的「查看输出」里看到；失败也会留一条记录，摘要写「上次更新失败（仍是 1.4.0）」。

## 隔离工作区（新建 Git Worktree）

- **分支名固定为 `pi/<类型>-<名称>`**：类型下拉可选 `feat` / `fix` / `chore` / `docs` / `refactor` / `test` / `perf` / `ci`（各带中文说明），切换类型只换前缀、名称保留。
- **删掉了「任务标识（简称）」**：它原先既决定分支名又决定目录名，却从会话标题整句种进来，会产出 `pi/请先了解一下本项目` 这种分支。
- **目录名默认「仓库名-分支名」**：`pi-desktop-fix-login`，不再是看不出仓库的 `7879f06a-fix-login`；从隔离工作区里再开一个也不会套娃。
- **不再预填名称**：打开对话框只放统一前缀（分支名 `pi/feat-`，子目录就是仓库名），名字由你自己写，光标停在末尾；名称为空时「创建」按钮禁用，不会建出 `pi/feat-` 这种半截分支。
- **对话默认「不加载历史对话」**：只有「从这个对话创建隔离工作区」这类明确入口才会替你选上。
- 新增一行预览：`将创建分支 pi/fix-x · 目录 pi-desktop-fix-x`。

## 已知限制

- macOS 安装包未签名 / 未公证，首次打开需要在「系统设置 → 隐私与安全性」放行；Windows 未做代码签名，SmartScreen 可能提示未知发布者。
- Linux 的 `AppImage` 需要 `libfuse2`；没有 FUSE 的环境请用 `tar.gz`。
- 本机需要有能运行的 `pi`；桌面端不内置 Pi 的副本。
- `/tree`、`/login`、`/share` 这类依赖 Pi 交互模式的功能只能在终端里用（`/` 菜单里不列出，敲出来会给说明）；`/llama` 目前会当普通文字发给模型（待修）。
- 出网方式只作用于应用自身与 Pi 子进程；**内置终端里的命令走你自己的 shell 环境**，不受这里影响。
- 终端依赖本机已装的 CLI 与 shell，应用不会代为安装、登录或配置。
- 文本文件读取 / 保存上限 20 MB，超过 2 MB 以只读大文件模式打开。

## 校验

发布产物附 `SHA256SUMS.txt`，覆盖三个平台的全部安装包。
