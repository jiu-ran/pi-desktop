# Pi Desktop v0.3.2

修掉 v0.3.1 里 `.md` 预览的三个问题：不能下滑、左边被切掉、有些文档点哪都没反应；就地编辑也从「带边框的等宽弹框」改成 Typora / Obsidian 那种**不画框、不换字体、不脱流**的样式。

## Markdown 预览修好了

- **不能下滑 / 左边被切**：v0.3.1 换成新容器时漏了 `.md-preview` 的滚动与内边距样式（`flex:1`、`overflow-y:auto`、`padding: 22px 32px 64px`、正文栏宽 860），而外层是 `overflow:hidden`，于是内容既滚不动、也贴着左边被裁掉。现在容器同时挂 `.md-preview`，版式与阅读排版全部回来。
- **有些文档点哪都没反应**：链接引用定义（`[标签]: url`，`CHANGELOG.md` 末尾就有一串）渲染出来是空的、不占顶层节点，但切块时算了一块 → 块数比节点多 1 → 对齐失败后整篇退化成纯预览。现在这类块单独标成 `linkref` 并在对齐时跳过；同时不再特殊对待 YAML front matter（markstream 不解析它，`---` 会渲染成分割线，按同样的规则切才对得上）。

## 就地编辑：不画框，就像在文档里打字

- 编辑框不再绝对定位浮在文档上，而是**插进文档流**：原来那一块隐藏、后面的内容正常让位；外面包一层块级容器承接原元素的外边距（`textarea` 的外边距不合并，直接搬会让整篇下移，实测 38px → 现在 0～1px）。
- **字号、字重、行高、字体、颜色照抄渲染结果**：编辑标题就是标题那么大，编辑代码块才是等宽；没有边框、没有底色、没有阴影，屏幕上只有光标在动。
- 高度按内容自动增长（`rows=1` + 先压 0 再读 `scrollHeight`，否则默认两行高）。
- 光标落在你点的那个位置附近，不再总是跳到末尾；点到工具栏、别的面板也会提交，`Esc` 取消、`Ctrl+Enter` 立即提交。

## 顺带修

- `shared/notify-text.ts` 里 `/s+/g` 的笔误（本意 `/\s+/`）会把字母 `s` 一起删掉，导致 `Connection reset` / `connection refused` 这类报错永远匹配不到「网络连接失败」。

## 校验

- 版式断言：预览可纵向滚动、左间距 ≥ 20px、无横向溢出、正文栏宽 860px、字号 14.5px。
- 就地编辑断言：在文档流里（`position: static`、父级 `.md-block-editor-host`）、无边框、无底色、字号与字重等于原渲染元素、原块 `display:none`；**切进编辑态后其后所有块的位移 ≤ 3px**（实测 1px）。
- 滚动到中段点击块，编辑框落回原位（±1px）；点到编辑区外能收起。
- 真实 `CHANGELOG.md` 端到端回归：195 块 === 195 个渲染节点，点段落可在预览里直接改。
- 反向验证：把「链接引用定义不占节点」的判定改回恒真 → 直接报「真实文档必须能对齐，aligned=0，blocks=0，slots=195」，即用户看到的现象。
- `npm run check` 全绿；Electron 冒烟 18 步 PASS。
