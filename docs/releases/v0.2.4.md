# Pi Desktop v0.2.4

长会话卡死的根治版：会话文件改为增量解析，启动与刷新都加了兜底，子代理改成独立一行并可点开对话。

## 修复

- **长会话会把整个界面卡死**：会话文件一大（实测 85MB / 1.2 万条消息），每次恢复历史、向上翻页都会把整份文件读进来重新 `JSON.parse`（约 360ms / 次）；而窗口绘制与 IPC 都在主进程，所以一卡就是整个窗口不动、标题栏以外的内容不再重绘。现在只解析新增的完整行，同一场景 **360ms → 7ms**。
- **会话列表会为了找名称把文件扫到开头**：没有重命名过的会话，读名称时会一路回看到文件开头（78MB 文件约 200ms），而流式期间会话列表要反复刷新，主进程被连续阻塞。现在最多回看 2MB，同一文件只扫新增的尾部（追加后 0ms）；文件被重写时用尾部指纹识别并整份重扫。
- **启动卡住时界面永远停在「启动中」**：`open()` 等待 Pi worker 没有总超时，worker 起不来时只能重启应用。现在启动 25 秒、读取快照 15 秒没结果就报错，并清掉这次半启动的 worker——点一下项目即可重新启动。
- **会话刷新可能变成 0ms 自旋**：会话列表刷新原来用 `setTimeout(…, 0)` 重排，事件密集时容易「刷新 → 写回 → 再刷新」把主线程刷满。现在有 200ms 最小间隔，连续重排按 2 的幂退避到最多 2 秒，安静下来自动恢复。
- **子代理长时间卡在某一步没有反应**：以前只有「运行中」转圈。现在卡片每秒刷新已用时长；扩展没有回传结构化进度（老版本 `pi-subagents`）时也会显示任务与状态，不再退化成只堆原始参数的卡片。
- **会话列表时间一直停在几天前**：侧栏用的是会话文件头里的创建时间。现在取「最近活动」（文件头时间与文件 mtime 取较大者），刚说过话就是「刚刚」。
- **右侧大纲滚到底还高亮倒数第二轮**：内容短或活动组折叠后，最后一条用户消息越不过判定线。现在滚到底直接标最后一轮。
- **复制按钮落在对话中间**：引导（steering）消息会把一轮拆成多段。现在只保留整段对话最后一段回复的复制按钮，且必须真的结束。
- **草稿只保存文字，不保存附件**：图片、文件、文件夹附件现在一起进草稿；恢复时逐个重新校验，失效的跳过并提示。

## 改进

- **子代理独立一行**：`subagent` / `parallel` / `review` / `bg_wait` 不再折进活动组，单独占一行：代理名 · 状态 · 任务 · 工具数/token/已用时长，失败原因直接列在下面；点一下打开这个子代理自己的对话（并行时左侧可切换子任务）。弹窗里的任务书改成独立的可滚动「任务」块，高度随内容自适应。
- **主进程卡顿日志**：超过 1 秒的阻塞写入 `userData/main-lag.log`，再遇到「界面卡住」能直接看出卡了多久。
- **升级后清理无用内容**：更新下载完成与启动时清掉旧版本安装包（只保留最新一个），`userData/updates` 不再随版本数膨胀；运行时缓存超过 512MB 才清理。只动这两类目录，会话、设置与用户文件不碰。
- **冒烟检查卡住时能定位**：单个检查超时后用调试协议暂停渲染进程并打印调用栈，而不是只给一句「整体超时」。

## 技术细节

- `electron/session-history.ts`：缓存解析后的条目与已读字节偏移，只解析新增的完整行（末尾半行留给下次）；文件被重写或变短时整份重扫。分支解析（`parentId` 树）抽成 `messagesFromEntries`，增量时只重算消息列表，不重新 `JSON.parse`。
- `electron/session-name.ts`：冷启动扫描上限 2MB；同一文件按 `size + mtime + 末尾 1KB 指纹` 判断是否可增量，追加后只读新增字节。
- `packages/ui/src/shared/refresh-backoff.ts`：会话刷新的最小间隔与退避（200ms → 最多 2s，安静 3s 复位）。
- `packages/ui/src/shared/outline.ts`：大纲高亮按「顶部越过 + 是否到底」计算，短会话与折叠内容也能标对。
- `packages/ui/src/shared/composer-draft.ts`：草稿存成 `{ text, attachments }`，兼容旧的纯文本格式。

- 子代理对话弹窗只读取扩展写在会话目录里的记录；扩展未落盘会话时只能看最终输出。
- 会话历史目前仍在主进程内存里保留完整消息列表（85MB 会话约 285MB 堆），只是不再重复解析；后续可以改成按需分页读取。
