# Pi Desktop v0.2.0

本次将 `thinkrail` 工作台优化分支合并到主版本：重做聊天与面板布局，加入真实交互终端、安全的 Git 分支管理，以及编辑器、更新和会话可靠性改进。

## 主要新增

### 真实终端与后台命令

- 接入 **node-pty + xterm.js**：Windows 使用 ConPTY，macOS / Linux 使用系统 PTY，可运行本机已安装的 Pi、Claude Code、Codex、vim、数据库客户端等交互程序。
- 终端默认作为**可选插件关闭**，在「设置 → 终端」启用；支持系统 shell、PowerShell、Git Bash、Bash / Zsh / Fish 和自定义可执行路径。
- 顶部横向会话标签、多会话独立屏幕、标签 × 结束并关闭、全宽画布、可调整高度与常驻后台命令栏。后台命令不会发送进当前 PTY，也不会切走全屏程序。
- 保留 ANSI 颜色与样式；选中后复制、快捷键粘贴、Ctrl+C 中断、Tab / 方向键、全屏滚轮内容翻页和失焦竖线光标；菜单跟随深浅主题。

### 版本控制与分支管理

- 五个明确入口：**更改 / 分支 / 历史 / 工作区 / 快照**。
- 已暂存、未暂存、未跟踪独立分区，支持路径搜索、Agent 筛选、单文件与分组暂存 / 取消暂存，以及提交、获取 / 拉取 / 推送。
- 可搜索本地 / 远程分支，支持**切换本地分支、新建并切换、从远程创建本地跟踪分支**；显示上游、最新提交和其他 worktree 占用状态。
- 切换前保护未提交改动、未保存草稿和运行中的 Agent 任务；不会自动丢弃、强制检出或 stash。写操作仅限项目目录等于仓库根目录。
- 同一文件的索引 Diff 与工作区 Diff 分开比较；会话快照不再误标为已提交。实时 Diff 可写行内评审意见并汇总到对话输入框。
- 隔离工作区：从 HEAD 创建独立 `pi/` 分支与 worktree，作为新项目打开，方便并行处理任务。

### 聊天与编辑器

- 新的空会话首页、起点卡片、项目侧栏与输入框；优化窄窗口、深浅主题和面板布局。
- 工具活动分组折叠、搜索命中自动展开、长用户消息折叠、技能调用卡片、对话大纲高亮、任务重命名和主题化悬停提示。
- 会话用量弹层展示 Pi 返回的 Token / 缓存 / 费用，不自行估算。
- **Ctrl/Cmd+P 快速打开文件**、最近文件、多项目独立页签与草稿、编辑器标签右键菜单及键盘导航。

## 可靠性与安全修复

- 文件保存绑定打开时的项目与内容版本，同一文件串行原子写入；检测外部修改冲突并保留草稿，可明确选择重新读取或覆盖保存。
- 修复切换项目、关闭标签、停用插件或移除项目时的草稿丢失风险；切换分支后关闭旧源码与实时 Diff 标签，避免旧基线误保存。
- 更新下载支持取消、超时、摘要校验与原子替换；修复取消移除仍删除项目，以及更新架构 / 版本匹配问题。
- 修复分叉会话历史串台、会话切换期间的未知文件错误、中文 UTF-8 文件误判二进制、Git 中文 / 空格路径解析、窄区域变更条逐字换行等问题。
- 渲染进程显式使用 CSP，Markdown 禁止不可信脚本 / 事件属性；图表按需加载，时序图恢复正常。
- 强化退出清理、Windows PTY 自然退出与进程回收，并加入终端、编辑器、Git 和网络 Electron 回归检查。

## 下载与校验

- **Windows x64**：`Pi.Desktop.Setup.0.2.0.exe` 安装器，或 `Pi.Desktop-0.2.0-win.zip` 便携包。
- **macOS Apple Silicon（arm64）**：`.dmg` 或 `-arm64-mac.zip`。
- **Linux x64**：`.AppImage` 或 `.tar.gz`。
- 下载后可使用同页的 `SHA256SUMS.txt` 校验文件。Windows 使用 `Get-FileHash <文件> -Algorithm SHA256`；macOS 使用 `shasum -a 256 <文件>`；Linux 使用 `sha256sum <文件>`。

## 升级提示与已知限制

- 从 0.1.x 升级后，终端需在设置中主动启用。CLI 与 shell 必须已安装，应用不会代为安装、登录或配置。
- 系统安装包**未代码签名**：Windows 可能提示未知发布者，macOS 可能需要在「隐私与安全性」允许打开；本次 macOS 产物为 arm64，不包含 Intel 安装包。
- Linux AppImage 需要 FUSE；无 FUSE 环境可使用 `.tar.gz`。
- 终端宿主保留最近 1 MB 原始输出，界面保留 500 KB；刷新后只能恢复尾部记录。
- 文本读取 / 保存上限 20 MB，超过 2 MB 以只读大文件预览打开。
