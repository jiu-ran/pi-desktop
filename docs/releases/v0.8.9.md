# Pi Desktop v0.8.9

四件事，都围绕「项目文件」这块：**文件树能排序**、**磁盘上的改动会自己跟上**、**表格不再整行闪色**、**工具栏少一个容易误点的按钮**。

## 文件树与已打开的文件跟随磁盘变化

以前界面只认自己发起的操作。Agent 跑工具改了文件、你在别的编辑器里存了盘、git 切了分支，文件树还是旧列表，打开的页签还是旧内容 —— 只能手点刷新，而刷新还会丢掉草稿。

- **文件树自动更新**：外部新建 / 删除 / 改名后直接出现或消失，不用点刷新。
- **编辑页自动同步**：页签没有未保存修改时，磁盘一改内容就跟着变（内容没变则什么都不做），工具栏短暂显示「已同步磁盘」。
- **有草稿时绝不覆盖**：顶部挂一条提示 ——「磁盘上的 `x` 已更新 / 可能是 Agent 改的，也可能是你在别的编辑器里改的；你的草稿还在，保存会覆盖磁盘内容」，出口是「用磁盘版本」和「保留草稿」。
- 文件被删除或移走时提示「已被删除或移走」，编辑器里的内容保留，可以复制出去。
- 忽略 `.git` / `node_modules` / `.pi` / `.pi-desktop`，也不理会原子写留下的临时文件；一批改动（比如切分支）合并成一次刷新。

## 文件树可排序

- 工具栏新增排序按钮，四个选项：**文件夹在前 · A→Z**（默认）/ **混合显示 · A→Z** / **文件夹在前 · Z→A** / **混合显示 · Z→A**，当前生效那项带勾。
- 名字比较走固定的自然排序，不依赖系统语言环境：`file2` 排在 `file10` 之前、大小写不敏感、中文排在拉丁字母之后；同名再按相对路径兜底，保证每次打开顺序一致。
- 根目录与每层子目录共用同一份设置，选择存在本地。

## 对话里的表格

- **去掉整行悬浮高亮**：markstream 默认在鼠标扫过时给整行上强调色底，表格行本来不能点，这个反馈只是噪声。
- 列宽改为按内容分配 —— 短列不再白占地方，长列也不会被挤成「Tomcat 实 / 现」这种断行。
- 表头底色比正文高一档（深色 `#25262a` / 浅色 `#eff0f3`），内边距与字号收紧，表头终于像表头。

## 项目文件面板去掉「打开其他项目目录」

打开项目是侧边栏的职责，面板里再放一个文件夹按钮容易误点（以为是在当前项目里操作）。现在工具栏只剩「只看变更 / 刷新 / 排序 / 新建文件 / 新建文件夹」；没有打开项目时给一句提示，不再给按钮。
