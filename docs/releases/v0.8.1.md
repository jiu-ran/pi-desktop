# Pi Desktop v0.8.1

修复外部工具锁定的 Git Worktree 无法清理问题；全面对齐并重构 Git 分支与状态操作按钮；优化全局可点击交互状态与悬停提示（Tooltip）穿透；增强工作区关闭与生命周期治理。

## Git 版本控制与工作树健壮性

- **强力解锁与孤儿工作区清理**：彻底解决外部 IDE / AI 智能体（如 JetBrains Air）锁定的 Worktree 在物理目录被删除后刷新依然残留的假删除问题。在移除时前置自动执行 `git worktree unlock`，使用双重 `--force` 参数强制清理，并增加 `--expire now` 绕过 Git 默认 3 天过期宽限期；增加残余元数据精准匹配兜底清理与真实状态核验。
- **分支配置隔离保护**：修复移除工作区保留本地分支时误删上游跟踪配置（`remote`/`merge`）的问题，仅精准剔除 Pi 自身写入的托管字段。
- **失效工作树显式标注**：当工作树物理目录在磁盘上已缺失时，徽标精准标注为警示红色的「已失效」，操作文案自动切换为「清理失效工作区记录」，消除对物理删除文件的误解。

## UI 交互与按钮规范全面优化

- **分支操作标签全列垂直对齐**：重构分支列表右侧 DOM 排布，将删除按钮置于胶囊标签左侧，所有状态标签（`当前` / `切换` / `检出` / `已占用` / `只读`）统一标准化为 52px 居中胶囊，紧贴右边距垂直对齐，彻底消除参差错落（Zigzag）。
- **删除按钮平滑淡入防抖**：本地分支删除按钮默认透明且不响应点击，鼠标悬停时平滑浮现，避免引起任何布局跳动与按钮移位。
- **全局可点击与禁用状态重塑**：重构全局 `.btn`、`.icon-btn` 与选择器交互状态，禁用状态统一采用 `not-allowed` 光标并增强与可点击元素的视觉明暗反差。
- **悬停提示（Tooltip）穿透修复**：修复子元素展示浮层提示时触发父级系统白底原生 Tooltip 的穿透与闪烁问题，子元素接管提示期间自动向上安全暂存父级原生的 `title`。

## 工作台治理与搜索增强

- **会话定时器泄漏修复**：在关闭项目时同步清理 `sessionRefreshes` 挂起定时器，规范化匹配 Windows 盘符大小写差异，关闭后优先切向就绪（`ready`）项目。
- **短提交哈希检索**：分支搜索框增加短提交 Hash 匹配索引，并支持按 `Esc` 键快速清空过滤条件。
- **克隆路径直观唤起**：克隆对话框位置输入框增设手型指针光标，支持点击输入框任意位置直接拉起系统文件夹选择器。

## 校验

发布产物附 `SHA256SUMS.txt`，覆盖 Windows、macOS 与 Linux 全部平台的安装包与二进制。
