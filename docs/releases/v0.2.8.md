# Pi Desktop v0.2.8

修 v0.2.7 里设置的「全局提示词」页排版：编辑器掉回了浏览器默认样式（白底、两行高），长提示词根本读不出来。

## 修复

- **「全局提示词」编辑器恢复主题样式**：重做设置界面时把 `.agents-editor` / `.settings-note` / `.settings-inline-icon` / `.settings-chip-btn` 四条样式一起删掉了（模板还在用），导致 `AGENTS.md` 的编辑框变成浏览器默认的浅底、两行高的小方框。
  - 现在编辑器跟随主题（深色底、等宽字体、12.5px/1.7 行高、8px 圆角、聚焦描边），并**占满卡片剩余高度**（最小 320px，可继续拖高），长提示词可以直接通读。
  - 路径说明用等宽小字并允许换行，长路径不再顶出卡片。
  - 顺带补回 `.settings-inline-icon`（刷新按钮里的图标尺寸）与 `.settings-chip-btn`（技能来源过滤胶囊）。

## 校验

- ✅ `settings.electron.mjs` 新增断言：打开「全局提示词」页后编辑器高度 ≥ 280px、宽度基本铺满、深色主题下背景不是白底、带圆角、路径显示为等宽字体；顺带留一张 `settings-dark-agents.png` 截图
- ✅ `npm run check` 全绿；Electron 冒烟 PASS

## 附：为什么漏了

重做设置界面时是整块替换 CSS 的，替换完只核对了「页面上看得见的部分」（这次改动过的 Tab），没有核对「模板里引用、但样式在新块里没被重写」的 class。现在补了一次全量核对：把 `SettingsModal.vue` 里用到的 class 和 `components.css` 里定义的做差集，只剩 Vue 过渡/表达式片段这类误报。
