# Pi Desktop v0.2.8

修 v0.2.7 里设置的「全局提示词」页排版：编辑器掉回了浏览器默认样式（白底、两行高），长提示词根本读不出来。

## 修复

- **「全局提示词」编辑器恢复主题样式**：重做设置界面时把 `.agents-editor` / `.settings-note` / `.settings-inline-icon` / `.settings-chip-btn` 四条样式一起删掉了（模板还在用），导致 `AGENTS.md` 的编辑框变成浏览器默认的浅底、两行高的小方框。
  - 现在编辑器跟随主题（深色底、等宽字体、12.5px/1.7 行高、8px 圆角、聚焦描边），并**占满卡片剩余高度**（最小 320px，可继续拖高），长提示词可以直接通读。
  - 路径说明用等宽小字并允许换行，长路径不再顶出卡片。
  - 顺带补回 `.settings-inline-icon`（刷新按钮里的图标尺寸）与 `.settings-chip-btn`（技能来源过滤胶囊）。

## 重连提示：一次故障只占一行

以前网络抖动时对话里会堆出七八块内容：每轮重试都新插一张卡片，卡片里还重复一遍 `Connection error.`，最后再来一条同样的错误——半屏都是同一件事。

- **同一次故障只留一条提示，就地更新**：`连接中断，2.0 秒后重试（1/3）` → `4.0 秒后重试（2/3）` → `重试 3/3 失败：网络连接失败`（或 `已重新连接（第 2 次重试）`）。
- **不再重复同一句错误**：重试进行中不另起一行显示原因；重试已失败并写明原因时，紧随其后的同一条错误直接忽略。
- **重复的相同提示合并**计数（右侧 `×N`），不再各占一行。
- **文案中文化**：`Connection error.` / `socket hang up` 等统一显示为「网络连接失败」。
- **排版紧凑**：重试提示从 ~70px 高（图标 + 文案 + 错误行 + 进度条）压到 **31px 单行 + 2px 细进度条**。

实测同一段「失败 → 重试 1 → 失败 → 重试 2 → 失败 → 重试 3 → 失败 → 收尾错误」：修复前 7 块、约 460px 高；修复后 **1 块、31px**。

## 运行日志：默认更小，上限可自己调

日志只在排查问题时有用，默认留 8MB 就够：

- **默认总量上限 8MB**（原来 100MB）。单文件上限按总量的 1/4 推导（限制在 512KB–8MB），保留个数按「总量 / 单文件」算，最多 12 个。
- **设置 → 运行日志 → 总量上限**：4 / 8 / 16 / 32 / 64 / 128 MB 可选，改完立刻生效，并顺手清一次超量文件（正在写的那个永远不删）。
- 页面上的「占用 x / 上限 y」和「单文件 … 轮转（最多保留 N 个）」跟着当前设置显示，不再是写死的数字。
- 手改配置文件里的非法值会被收敛到 1MB–128MB 之间。

## 修复（续）：提示浮层回调自激，界面真正卡死

0.2.7 修掉了「批量写回 title 时逐条量几何」的慢，但冒烟里又抓到两次卡死，栈是这样的：

```text
#0 restoreTitle  ← #1 restoreActive ← #2 scheduleShow ← #3 全局 title 回调
```

即：回调里写回 title → 又触发新的 mutation 记录 → 回调再跑 → 再写……形成微任务乒乓，主线程被占满。

- 现在回调**只收集目标元素**（去重），放到下一个宏任务里分批处理（每批最多 40 个），处理过程中产生的新记录留到下一批。即使还有来回写，主线程也能在批次之间让出去，界面不会整片卡死。
- 卸载时清空待处理队列与定时器。

## 待发送消息改到输入框上方

按反馈调整展示：排队 / 插话的消息**只在输入框上方**列出（带「待发送」呼吸标记、模式标签、三行预览、「编辑」与「全部撤回」），对话里那条乐观渲染的气泡在排队期间暂时隐藏，真正发出后才出现——同一条消息不会在两处重复。

## 残留清理：装新版本不再动你的项目

旧版本（0.2.5 / 0.2.6）曾把运行日志写进 `<项目>/.pi-desktop/logs`，并往仓库的 `.git/info/exclude` 追加一行 `.pi-desktop/`。日志在 0.2.6 已经改到安装目录，但这两样东西还留在项目里——看起来就像「装个新版本又改了我的本地设置」。

- 打开项目时自动清理旧痕迹：`.pi-desktop` 目录**只在里面除了 `logs` 什么都没有**时才删除；`.git/info/exclude` 只删我们写的那一行（精确匹配，其它行原样保留）。
- 有任何用户自己的内容一律不动，只记一条日志。清理失败不影响打开项目。
- 本机已实测清理：`Desktop/chat`、`Desktop/pi-desktop` 两处残留已清掉，复查无遗留。

## 附：为什么漏了

重做设置界面时是整块替换 CSS 的，替换完只核对了「页面上看得见的部分」（这次改动过的 Tab），没有核对「模板里引用、但样式在新块里没被重写」的 class。现在补了一次全量核对：把 `SettingsModal.vue` 里用到的 class 和 `components.css` 里定义的做差集，只剩 Vue 过渡/表达式片段这类误报。
