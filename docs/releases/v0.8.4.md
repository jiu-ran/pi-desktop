# Pi Desktop v0.8.4

断网之后的收尾终于顺了：重连成功不会再留一张过期的「网络连接失败」红卡，也不会什么都不说 —— 它会变成一条「✓ 已重新连接」。

## 重连后的提示

- **走了自动重试**：`↻ 连接中断，正在重试（1/5）` → `✓ 已重新连接（第 N 次重试）`。被这次重连取代的失败卡一起收掉，不会重复堆叠。
- **没走自动重试**（关掉了自动重试，或者自己点重发）：下一条正常回复到达时，那张「网络连接失败 ×N」就地改写成 `✓ 已重新连接，任务继续` —— 既不留过期的失败信息，也不是什么都不显示。
- **非网络错误保持原样**：工具报错这类失败卡不会被改写。判定只认网络类错误（`Connection error/reset/closed/refused`、`socket hang up`、`fetch failed`、`ECONNRESET/ETIMEDOUT`）。
- **彻底失败仍然说清楚**：重试用尽后显示 `重试 N/M 失败：<原因>`，不会把没连上的情况藏起来。

## 输入框草稿

- **刷新 / 关窗不再丢附件**：草稿写入有 400ms 防抖，之前网页重载或退出时没补写，刚加上的附件会丢（正文因为写得更早还在）。现在 `pagehide` / `beforeunload` 会先把待写的草稿落盘。
- **附件恢复等就绪再校验**：重载后工作区还没授权完成时，附件校验会失败并被当成「已不可用」跳过；现在等到工作区就绪、并重试几次，实在拿不到才提示。

## 已知限制

- macOS 安装包未签名 / 未公证，首次打开需要在「系统设置 → 隐私与安全性」放行；Windows 未做代码签名，SmartScreen 可能提示未知发布者。
- Linux 的 `AppImage` 需要 `libfuse2`；没有 FUSE 的环境请用 `tar.gz`。
- 本机需要有能运行的 `pi`；桌面端不内置 Pi 的副本。
- `/tree`、`/login`、`/share` 这类依赖 Pi 交互模式的功能只能在终端里用（`/` 菜单里不列出，敲出来会给说明）。
- 终端依赖本机已装的 CLI 与 shell，应用不会代为安装、登录或配置。
- 文本文件读取 / 保存上限 20 MB，超过 2 MB 以只读大文件模式打开。

发布产物附 `SHA256SUMS.txt`，覆盖三个平台的全部安装包。
