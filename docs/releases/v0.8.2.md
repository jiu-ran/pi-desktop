# Pi Desktop v0.8.2

这一版把 Pi CLI 的 `/` 命令补齐并逐条对齐，顺手挖出一个一直没生效的坑（项目信任）；终端里跑过的后台命令可以原地重跑，不用再堆一排标签；「重新连接模型」那张提示卡的动画也终于对上了真实时间。

## `/` 命令与项目信任

- **命令清单对齐 Pi 1.4.0**：Pi 的 24 条内置命令里，桌面端现在有 18 条等价实现，新增 `/trust`（项目信任）、`/import`（导入 `.jsonl` 会话）、`/changelog`、`/quit`，`/export` 额外支持导出 `.jsonl` 原始记录。
- **做不了的 6 条不再进菜单**：`/tree`、`/login`、`/logout`、`/share`、`/bug`、`/scoped-models` 依赖 Pi 的交互模式。菜单只列真能执行的命令；直接敲出来时菜单会解释「只能在终端里用」，回车给出替代做法并清空输入框，**不会**把它当普通文字发给模型。
- **项目信任现在真的生效**（此前的静默 bug）：Pi 只在项目里有 `.pi/{settings,mcp,extensions,skills,prompts,themes}` 这类资源时才校验信任，顺序是「信任记录 → `defaultProjectTrust` → 弹窗询问」。桌面端走 RPC 没有 TUI，最后一步拿不到答案就**一律按不信任处理**，于是项目级扩展、技能、MCP 全部静默不加载，而设置里的清单是按文件扫出来的，看起来一切正常。
  - `/trust` 可查看状态、写入「信任此项目 / 信任上一级目录 / 不再信任」，写完自动重启 Pi 进程让资源重新加载；
  - 「设置 → 扩展 → Skills」在需要信任但未生效时显示横幅与一键信任按钮；
  - 信任记录按 Pi 的格式写入 `<agentDir>/trust.json`（键排序、两空格、原子替换、支持祖先目录继承）。

## MCP

- **`/mcp` 不再被 Pi 自带扩展顶掉**：`mergeCommands` 原来让远端命令优先，而 Pi 自带扩展里就注册了一条 `mcp`，于是敲 `/mcp` 会跑进扩展的流程（对话里还会多一条 `/mcp` 消息），打开不了 MCP 设置页。现在撞名时桌面端优先。
- **补上 OAuth 登录**：需要授权的服务在设置页显示「登录」（已授权的显示「重新登录 / 退出登录」），转发给本机 `pi mcp login|logout`，浏览器里完成授权、凭据由 Pi 保存，完成后自动刷新服务状态并重新探测工具。

## 终端与后台命令

- **后台命令原地重跑**：选中跑过的后台命令、输入框留空时，右下角按钮变成「重新执行」，Enter **在这个标签里**再跑一次 —— 输出清空、标签位置不变，不再每次都开一个新标签。顶部刷新按钮做同一件事，「编辑」图标只把命令填回输入框。
- **停止 / 重跑运行中的任务**：重跑会先结束旧进程并等它真的退出（最多 4 秒）再起新的，避免同目录两份进程同时写文件；等不到就提示稍后再试。
- **修掉标签重复**：`start` 事件可能比启动响应先到，之前会在列表里留下同一个 id 的两条记录，现在统一重排，既不重复也不跳位。

## 重新连接提示卡

- **倒计时真的在走**：以前正文写死「连接中断，3.0 秒后重试」，秒数是事件那一刻算出来的，时间在走数字不动，第二次重试还会沿用旧值。现在正文只说「正在重试（n/m）」，秒数由界面按 deadline 每 200ms 更新，到点变成「正在重试…」。
- **进度条每次重试重新开始**：原来动画时长靠 CSS 变量，改变量不会让已经跑完的动画重来，第二次重试时细条一直停在 0。
- **重连时图标转圈**：成功变 `✓`、彻底失败变 `×`，收尾文案与配色不变。

## 工程

- 新增检查：`pi-commands`（24 条命令 ↔ 桌面端实现双向对齐）、`project-trust`（`trust.json` 格式与继承）、`slash-merge`（撞名让位 / 分组 / 过滤排序 / 解析）、`terminal-rerun`（原地重跑 / 先停再跑 / 事件先到不重复）、`retry-notice`（倒计时取整 / 文案 / 进度条重启）。
- 撞名规则、`/` 命令对照表与项目信任写进 `docs/pi-compatibility.md`，Pi 升级加命令时 `pi-commands` 会直接报红。
- 依赖：`npm audit` 的 high / critical 已清零（`joi`、`follow-redirects` 补丁升级，属于 electron-builder 构建期链路）。剩余 moderate 来自仅构建期使用的 `electron-builder` 工具链（`@electron/asar` 内的 `minimatch`），不进安装包。

## 已知限制

- macOS 安装包未签名 / 未公证，首次打开需要在「系统设置 → 隐私与安全性」放行；Windows 未做代码签名，SmartScreen 可能提示未知发布者。
- Linux 的 `AppImage` 需要 `libfuse2`；没有 FUSE 的环境请用 `tar.gz`。
- 本机需要有能运行的 `pi`；桌面端不内置 Pi 的副本。
- `/tree`、`/login`、`/share` 这类依赖 Pi 交互模式的功能只能在终端里用（菜单里不列出，敲出来会给说明）。
- 终端依赖本机已装的 CLI 与 shell，应用不会代为安装、登录或配置。
- 文本文件读取 / 保存上限 20 MB，超过 2 MB 以只读大文件模式打开。
