# Pi Desktop v0.2.2

小版本更新：子代理渲染改为可选插件，修复对话、Git 面板与提示浮层的多处显示问题。

## 新增

- **子代理插件**：子代理工具（`subagent` / `parallel` / `review` / `bg_wait`）的结果会渲染成子任务清单——代理名、状态（完成 / 失败 / 超时 / 停止）、耗时、工具数、轮次、token、当前工具与失败原因；失败项默认展开明细，运行中的任务随进度实时刷新。
  子代理来自 `npm:pi-subagents` 扩展，并非所有用户都安装，因此做成「对话区域」插件：可在插件管理中停用，停用后这些工具回退为通用工具卡片；没有该扩展的用户完全无感。
- **输入框草稿持久化**：草稿按「项目 + 会话」保存在本机，重启应用后自动恢复；发送成功或删除会话时清理，最多保留 40 条。新会话的临时文件名会迁移到真实会话键上。

## 修复

- **活动组一直显示「失败」**：活动组会把一段连续的工具 / 思考折叠成一组，可能横跨多个回合。旧实现只要组内出现过一次失败就整组标红，随后重试成功也照样报红。现在看最后一个已结算的工具——以失败收尾才标红；中途失败但已恢复时只留弱提示「失败 ×N」，失败信息不会丢。运行中的重试（还没结束）也不会提前报警。
- **提示浮层出现原生白底**：Vue 在流式期间会反复改写响应式 `title`，旧实现只在显示时移除一次，导致原生白底提示和主题提示同时出现。现在悬停即接管 `title`，用 `MutationObserver` 持续同步内容，离开时还原；浮层位置也会夹在当前视口内，锚点滚出可见区域时不再跑到屏幕外。
- **引导 / 追加消息发出去看不到**：流式期间发送的 steering / followUp 消息以前不做乐观渲染，要等重开会话从文件读回才显示。现在与普通发送一样立即插入对话，投递失败时再撤回。
- **对话里出现空的「工具」卡片**：`toolcall_start` / `toolcall_delta` 只带 `contentIndex` 与 `partial`，没有 `id` / `name`；旧实现按 `update.id` / `update.toolName` 取值，会建出无名占位块。现改为从 `partial.content[contentIndex]` 取 id / 名称，并在消息结束与任务结算时清理残留块。

## 改进

- **Git 提交框**：高度翻倍（108px 起）并随内容自动增高，上限 `min(560px, 55vh)`；去掉右下角的鼠标拖拽手柄，高度只跟随内容，窄窗口下不会把变更树挤没。
- **Git 变更树**：分区标题放大到 15px 并改用独立配色，第一层与标题左对齐，层级改用引导线表达；「会话快照」区去掉每行重复的徽标与代理圆点。

## 技术细节

- 新增 `packages/ui/src/plugins/subagent/`：`index.ts`（对话区域插件定义）、`summary.ts`（`details` 归一化，纯函数）、`SubagentTool.vue`（子任务清单）、样式随插件放在 `styles/subagent.css`。
- `BlockView.vue` 按插件注册表决定渲染路径：未注册或被停用即回退 `GenericTool`，核心不再硬编码子代理工具名。
- `transcript.ts` 在 `tool_execution_update` 时同步 `partialResult.details`，实时进度才能驱动清单。
- `shared/activity.ts`：`errored` 改为「最后一个已结算工具是否失败」，新增 `failedCount` 用于弱提示。
- 新增 `shared/composer-draft.ts`：草稿键为 `cwd|sessionFile`，写入按 400ms 防抖，最多 40 条。
