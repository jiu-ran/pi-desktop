# Pi Desktop v0.2.1

小版本更新：修复会话重命名显示同步、优化 Git 提交框布局。

## 修复

- **会话重命名显示不同步**：Pi CLI 重命名会话时会追加 `session_info` 记录到文件末尾，但桌面端仍读文件头旧名称。现在从文件末尾倒序读取最新名称，支持长会话、连续重命名、清除名称和缓存失效；重命名事件即时更新侧栏和顶部标题，RPC 期间切换会话不会改错线程。
- **Git 提交框高度调整**：输入框支持鼠标拖拽调整高度（54px ~ 280px），提交按钮和提示文本的布局更灵活；窄屏幕（< 330px）下按钮改为 2 列并排，提示文本显示在下方，避免互相挤压。

## 技术细节

- 新增 `electron/session-name.ts`：从文件末尾倒序读取最新 `session_info` 记录，按 64KB 块迭代，处理 UTF-8 多字节字符拼接和不完整行。
- 改进 `refreshSessions()` 合并已命名线程状态而不是直接替换列表，避免列表刷新覆盖手动重命名的新名称。
- Git 样式改进：提交框使用 flexbox 布局，输入框和按钮在不同宽度下都能正确显示；响应式规则优化窄屏幕的排列。
