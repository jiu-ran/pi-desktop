# Pi Desktop v0.3.1

Markdown 文件的阅读与编辑改成 Typora 式混合预览；修掉「思考/流式输出时上滑被弹回底部」；排队消息可以单条撤回、发出的顺序也对了；子代理异步派发不再显示成看不懂的英文和机器 JSON；输入框不再莫名停在三行高。

## Markdown：默认预览，点哪块改哪块

- 打开 `.md` 默认就是渲染后的样子（标题、列表、代码块、表格、引用都是排好版的），**不再左右分栏**。
- 点某一段文字，**只有这一块**变成源码编辑框（等宽字体、宽度贴合原块），其它块继续以渲染结果展示；改完点别处或 `Ctrl+Enter` 写回全文，`Esc` 取消。自动保存、`保存` 按钮、脏标记照常生效。
- 切块与渲染结果严格对齐：markstream 每个顶层节点渲染成一个 `.node-slot`，块数对不上时（罕见扩展语法）自动退化成纯预览，不会让你点到错位的段落。
- 视图只剩两档「预览 / 源码」，默认预览；旧配置里的分栏选项自动归一到预览。
- 阅读排版一并调整：正文 14.5px / 行高 1.78、最大宽度 860px；h1/h2/h3 重新分级（h2 带下边框）；引用块用强调色竖线 + 淡底；行内代码做成 chip；表格表头底色 + 斑马纹；任务列表复选框跟随强调色；链接带下划线、图片圆角。

## 流式输出时上滑不再被弹回底部

- 以前贴底后会开启 120ms 的「忽略滚动事件」窗口，而流式和思考几乎每几十毫秒贴一次底，这个窗口**一直在**——你的上滑被当成程序化滚动吞掉，于是又被拉回底部。
- 现在改成按值判定：只有滚动位置还停在上次自动贴底的位置才算程序化滚动；滚轮向上立刻暂停跟随，已经排队的贴底帧用 `followEpoch` 作废。
- 思考阶段（思考块、代码高亮、图片异步撑高）走同一条判定，同样不会被拉回底部；上滑后右下角出现「回到底部」，点了才恢复跟随。
- 顺带修掉空会话时自动贴底一直不生效（`.timeline` 里还没有内容容器，`ResizeObserver` 挂不上）。

## 排队消息

- **顺序**：新排队条目插到上一轮输出中间的问题修好了——只有「上一轮队列里有、这一轮没了」的条目才会被挪到末尾，历史消息不会跟着重排。
- **单条撤回**：每条排队卡片右侧多了 `编辑 · 撤回`，撤回只删这一条，其余按原顺序重新入队；失败时保留原队列并提示。
- **编辑后图片不再重复**：图片按提示词逐条带回，不再把整组图片塞给同一条消息，气泡里的缩略图也只算一次。
- 鼠标悬停的提示气泡改成深色浮层，子元素自己的提示也能正常接管（不再弹原生白底 tooltip）。

## 子代理

- 异步派发（`asyncId`）不再显示成「子代理 · 子代理」的空标题，改为按类型给出「子代理 / 工作流 / 并行子代理」并标注已派发。
- 进度 widget 不再把扩展写给模型的英文（`Detached. Return control now…`）和 `PI_SUBAGENT_ASYNC_JSON:` 机器 JSON 原样打印，改成「子代理进度 · N 个运行中」+ 每行任务状态，原始 JSON 折进可展开的详情里。

## 输入框

- 切会话、切项目、拉动面板宽度后，输入框偶尔停在好几行高：高度是 `autosize()` 写的内联样式，只在草稿变化时重算。现在空输入交还 CSS 高度，切会话/切项目/窗口尺寸变化都会重算。

## 校验

- 新增 `markdown-blocks.check.ts`（切块：标题/段落/列表/代码/表格/引用/分割线、setext、loose list、front matter、软换行、只替换目标块、CRLF 保真）、`autoscroll.check.ts`、`subagent-widget.check.ts`、`queue-view.check` 扩充。
- 新增 `markdown-blocks` 相关 Electron 用例：只有两档视图按钮且默认预览、6 块全部对齐、点标题块出现就地编辑框并预填源码、其它块保持渲染、改完写回草稿并更新预览、切源码正常。
- `autoscroll.electron` 增加「上滑后连续 `markdown:height-change`」用例：必须仍停在历史位置并显示「回到底部」。
- 反向验证：把滚动判定换回旧的 120ms 写入法，用例直接报「上滑后应出现「回到底部」提示」。
- `npm run check` 全绿；Electron 冒烟 18 步全 PASS。
