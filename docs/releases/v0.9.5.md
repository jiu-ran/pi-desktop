# Pi Desktop v0.9.5

这一版把「装完之后的第一眼」和「消息队列」两处不顺手的都处理了：默认窗口按你的显示器给一个舒服的尺寸、首启只留对话窗口、图片预览不再是一块灰底；队列里的消息编辑时不再被悄悄发出去，图片能删也能撤回。

## 首启只留对话窗口

以前一开就是三块岛：左边项目栏、中间对话、右边「项目文件」面板 —— 而没打开项目时，右边那块只有一句「先在左侧边栏选择或打开一个项目」。

现在：

- 右侧面板默认收起，点图标、打开文件、切到 Git 时才展开
- 没打开项目时左侧栏也不渲染（它那时只有一个空搜索框），打开项目后自动回来
- 标题栏的侧栏按钮在没有项目时置灰，不会「按了没反应」

## 默认窗口尺寸

默认值改成 **`1030×730`（DIP）**。在 1920×1080 开 125% 缩放的屏幕上是 **1288×912 物理像素**。

仍然自适应：不超过当前显示器工作区的 86%（小屏、竖屏、4K 高缩放都会收小，最小尺寸跟着降），多显示器按窗口所在的那台算，改分辨率 / 插拔外接屏后非最大化窗口会自动收回工作区。升级后第一次打开就用新尺寸（旧的状态文件不再沿用）。

## 图片预览的遮罩

以前遮罩写死 `rgba(0, 0, 0, 0.78)`，浅色主题下打开大图，图片以外就是一大片灰黑。

现在：浅色主题是雾白毛玻璃（`rgba(250,246,250,0.86)` + 26px 模糊），深色主题是墨黑；关闭按钮、`1 / 1` 翻页条、文件名都换成主题色，浅色主题下不再白字白底。

弹窗与命令面板的遮罩**保持原样** —— 设置弹窗本身就是玻璃质感，换成浅色遮罩后背景内容全透上来，实测反而读不清。

## 消息队列

### 编辑时不再被悄悄发出去

引导（steer）消息排在 Pi 的队列里，**随时会被插进当前回合**。你还在编辑框里改，它可能已经发出去了；保存时队列里找不到这条，编辑就静默丢失，对话里出现的是原文。

现在打开编辑框会先把这条从队列里拿走（其余消息按原顺序重新入队，这条的气泡继续隐藏），保存 / 取消时再按原位置放回。如果编辑过程中切换了会话或项目，会自动取消编辑，并把消息放回**原来那条会话**的队列 —— 不会既不在队列里也不在界面上。

### 编辑框里能删图片了

以前原有附件是只读标签，只有「编辑时新粘贴的」能删。现在每个附件都有 ×，删掉的图片会同时从提示词块、图片数据、气泡的附件列表里移除，不会又被带上。

### 撤回能带回图片

单条撤回 / 全部撤回以前只回填文字，图片就丢了。现在一起带回附件：文件 / 目录走附件校验重新挂回输入框，会话引用交给「引用对话」插件；「全部撤回」也会包含正在编辑的那条。

## 会话用量弹层

点弹层外面、或者点到别的程序 / 桌面（窗口失焦）就自动收起。以前弹层里的透明遮罩是 `position: fixed`，而输入框是玻璃质感（`backdrop-filter`），fixed 会相对输入框定位 —— 那块遮罩其实只盖住输入框自己，点聊天区关不掉。

## 开发体验

开发窗口加载失败（dev server 没起来 / 正在重启那几秒）会自动重试：600ms 一次，成功就把计数清零，连续失败约 36 秒才停手。以前只能停在 Edge 的「无法访问此页面」上手动点刷新。

## 校验

- `npm run check`：58 个纯逻辑 / 界面检查 + 3 个静态分析全部通过（新增 `queue-recall` 覆盖 hold / 保存 / 取消 / 删图 / 单条撤回 / 全部撤回 / 跨会话取消）。
- `go vet ./...` 与 `go test ./...` 通过。
- 宿主冒烟（host / PTY / 一次性命令 / 真实 Pi prompt / 界面 / 设置 / Git 与 worktree）全过，退出后无残留 Pi worker。
- 真机实测：窗口 1288×913 物理像素（目标 1288×912）、图片预览浅色雾白毛玻璃、用量弹层「打开 true → 点聊天区 false → 重开 true → 失焦 false」。

## 仍存在的限制

- **编辑期间消息悬空**：它已离开 Pi 队列，此刻强杀进程 / 崩溃，这条消息不会重发也不会留存（要彻底解决得把内容跟着草稿落盘）。
- **队列只能整体重排**：Pi 只提供 `clearQueue` + `steer` / `followUp`，所以编辑 / 取消 / 改投递方式 / 调顺序都是「清空后整队重新入队」，清空瞬间其余引导消息可能被立即投递（它们本来也要尽快送达）。
- **按文本匹配**：两条内容完全相同的排队消息，隐藏 / 撤回可能命中错的那条。
- **回填的图片依赖临时文件**：粘贴图片存在 `%TEMP%\pi-desktop-paste`，被清理后撤回会提示附件不可用。
- 安装包仍未签名，macOS 首次打开需要在「隐私与安全性」里放行。
