# Pi Desktop v0.8.5

对话界面现在能看出「这一下是不是外部服务在跑」：MCP 工具调用会标出服务名与次数，两种暴露方式都覆盖 —— 包括默认的 `codemode`（外部调用藏在脚本里）。

## MCP 工具调用标注

- **`direct` / `deferred` 暴露**：工具名本身就是 `mcp__<服务>__<工具>`，那一步带一枚 `MCP · github` 标记，卡片标题显示可读工具名（`search repositories`）而不是原始编号。
- **`codemode` 暴露（默认）**：外部调用藏在脚本里（`tools.mcp__<服务>__<工具>`）。界面会把它们从脚本里认出来，标记写成 `MCP · github ×2`（同一脚本里调了几次就写几次），组头摘要按**调用次数**计入「MCP N 次」。
- **多个服务**：`MCP · github +1 ×3`（首服务 + 其余数量）。
- **配色**：标记用强调色、比正文小一号，不抢「改动」的红绿，也不加边框色块。
- **宁可不标也不错标**：拼接出来的工具名（`tools["mcp__" + name]`）静态看不出来，就当没有；纯本地脚本不带标记。

## 已知的限制

- 标记里显示的是**脚本里的写法**：JS 标识符会把非法字符换成 `_`，所以配置里叫 `dev-radius` 的服务在脚本里是 `tools.mcp__dev_radius__search`，标记显示 `MCP · dev_radius`（不做猜测性还原）。
- 标注只表达「调用了外部服务」，**不拦截**：要限制某个服务能不能用，仍然在「设置 → MCP」里改暴露策略。

## 已知限制

- macOS 安装包未签名 / 未公证，首次打开需要在「系统设置 → 隐私与安全性」放行；Windows 未做代码签名，SmartScreen 可能提示未知发布者。
- Linux 的 `AppImage` 需要 `libfuse2`；没有 FUSE 的环境请用 `tar.gz`。
- 本机需要有能运行的 `pi`；桌面端不内置 Pi 的副本。
- `/tree`、`/login`、`/share` 这类依赖 Pi 交互模式的功能只能在终端里用（`/` 菜单里不列出，敲出来会给说明）。
- 终端依赖本机已装的 CLI 与 shell，应用不会代为安装、登录或配置。
- 文本文件读取 / 保存上限 20 MB，超过 2 MB 以只读大文件模式打开。

## 校验

发布产物附 `SHA256SUMS.txt`，覆盖三个平台的全部安装包。
