# Pi Desktop v0.5.1

这一版几乎全是「看得见的顺眼」：待发送的卡片瘦成两行、长队列只滚卡片不滚整页；执行记录里的增删行数和耗时终于贴在行尾对齐；对话里的本地图片能显示出来，还能点开放大。另外修好了压缩上下文撞输出上限、撤回排队消息删错气泡等几个具体问题，并清掉了一批没人引用的代码和样式。

## 对话里能看图了

- **本地图片直接显示**：以前 `![](D:\截图.png)` 这种本地路径在对话里只会显示一个「加载失败」，现在渲染前就把本地文件读成 data URL 再交给渲染器。盘符路径、UNC、`file://`、协议相对的 CDN 地址都认，工作区之外的绝对路径也能读（只读、只认图片类型、单文件上限 20 MB）。
- **点一下看大图**：正文里的图片可以点开放大，也可以聚焦后按 `Enter` / 空格；图片带「点击放大」提示，鼠标移上去是手型。
- **SVG 保留原始行为**：对话里的 svg 图片不做替换——渲染器会把 svg 整块丢掉，替换了反而连「加载失败」的提示都没有。

## 待发送卡片

- **附件只留文件名**：图片和文件不再带类型图标、类型徽标和大小（这些全都删了，包括为拿大小加的 IPC），只剩等宽小字 + 淡底的文件名。
- **两行版式**：上面一行附件、下面一行「投递方式 + 单行正文」，正文过长省略，悬停才出现编辑 / 撤回按钮；纯文本卡片不再比带附件的矮一截。
- **降噪**：「待发送」只在表头出现一次；拖动把手换成 2×3 点阵，不悬停不显示；「拖动排序 · Alt+↑/↓」这类说明挪进把手的 `title`。
- **键盘排序**：卡片可聚焦，`Alt+↑ / Alt+↓` 与拖拽走同一套换位逻辑；长队列只滚卡片区域，不带着整个对话一起滚。

## 执行记录

- **增删行数与耗时靠右对齐**：每行的 `+N` `−N` 和耗时收进同一个右对齐、等宽数字的区块，路径再长也不会把数字推到中间。
- **组头补总账**：合并的步骤组在标题后面显示整组的 `+N −N`，单个步骤没有增删就不显示 `+0`。
- **合并行补耗时**：一步合并了多个工具时，耗时口径改成各步之和。

## 修复

- **压缩上下文撞输出上限**：摘要任务本身会被思考吃掉预算，现在遇到上限临时把思考等级降到 off 重试一次再还原。
- **自动压缩不再谎称「已重试」**：失败提示只对真的重试过的场景说重试过。
- **撤回排队消息删错气泡**：同一条消息在多处出现时，按出现次数删除，而不是删掉第一个匹配。
- **草稿只回正文**：把排队消息撤回成草稿时，`[文件: …]` 标签不再被塞进输入框；草稿按时间戳裁剪，改写过的不会被误当成旧的先删。
- **升级 Pi 之后空闲工作区不重启**：现在会重启，避免新版本的能力一直不生效。
- **五个早就不存在的 CSS 变量名**：`var(--x)` 取不到值是静默失效，这类问题现在是 `npm run check` 里的一条断言。

## 文件图标

试过两套现成图标库（Seti UI、Material Icon Theme）之后全部删掉了：冷门扩展名要么退化成文字徽标（不想要），要么所有文件长成同一张纸，生成脚本漏收集兜底名还会让文件夹显示成文件。现在只有两枚自绘图形——文件夹和文件，`currentColor` 跟随主题，不再按类型上色。

## 清理

- 删掉没人引用的 `MarkdownPreview.vue`、`pi-mark.svg`、`.md-preview` 阅读版式、字体目录里的孤儿许可证、以及十几处「声明后全仓再没出现过」的导出。
- 删掉 160 个没人挂的 CSS 选择器（重复定义、已删功能的残留）。
- 把写好却漏挂的 `markdown-block-edit` 检查接进 `npm run check`；README 里指向不存在文件的链接修掉。

## 兼容性

- 配置项与旧版本兼容，升级后设置保留。
- 待发送队列里用过的「类型徽标 / 文件大小」显示已移除，属刻意取舍。
