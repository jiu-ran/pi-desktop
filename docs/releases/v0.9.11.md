# Pi Desktop v0.9.11

这一版把内部一批「容易出事」的地方修掉了：更新包开始验签、工作区授权收口、RPC 死锁与 Worker 池竞态、一批资源泄漏；同时把上两轮为了安全而牺牲的可视化收回来 —— **PDF / Word 的文本 diff、明文 http 图片、项目外文件保存都恢复了**。

> ⚠️ **这一版需要手动升级一次**。更新包签名校验从 0.9.11 起生效，0.9.10 及更早的客户端不验签。

## 更新包签名（需要手动升级一次的原因）

以前「检查更新」等于「无条件执行 GitHub 上的附件」：发布账号被盗，装上什么都拦不住。

现在下载流程是：

1. 取 `SHA256SUMS.txt` 与 `SHA256SUMS.txt.sig`
2. 用**编译进客户端的 ed25519 公钥**验签
3. 用**验过签的清单**里的 SHA-256 比对安装包
4. 公钥缺失、签名缺失、验签失败 → 不自动安装，只给「到发布页手动下载」

签名在 CI 里完成（私钥在 GitHub Secret 中，公钥在构建时注入），`install()` 还会再拒一次未签名的包。

**为什么必须手动升级一次**：0.9.10 及更早的版本没有内置公钥，也不会去取 `.sig`。你手动装上 0.9.11 之后，之后每次自动更新才真正受保护。

## 可视化：把过头的限制收回来

桌面端的本分是把 CLI 的内容如实呈现，所以这轮把几条「安全换体验」的限制反向调整：

- **PDF / Word / 图片的 diff 恢复可读**：`git diff/show/log` 不再加 `--no-textconv`。外部 GUI diff 仍然屏蔽（它的输出拿回来解析不了）。
- **远程图片默认直接显示**：对话与表格单元格里的 http(s) 图片自动加载，明文 http 也正常显示。介意「本机 IP / Referer / 阅读行为被送给图床」的，可以在「设置 → 对话 → 自动加载远程图片」关掉，关掉后回到占位 + 点一下才加载。老版本存下来的旧默认值会做一次性迁移，之后尊重用户自己的选择。
- **项目外文件可以直接保存**：不再要求「先在编辑器里打开过」。保留真正护数据的检查：20 MB 上限、二进制 / 图片拒绝在文本编辑器里保存、`revision` 不匹配（磁盘上已被别人改过）时阻止覆盖。

## 安全

- **工作区授权收口**：写盘、终端、Git、项目级 MCP 配置只接受用户打开过的项目目录；项目外路径拒绝 UNC / 网络位置（Windows 读 SMB 会把 NTLM 凭据发给对方）；MCP 的 `env` / `headers` 按 key 合并掩码值（不再用空串覆盖令牌），读改写放进文件锁并走原子写；日志脱敏补 AWS 访问密钥与 JWT；会话引用正文里的 `</session>` 转义。

## 修复

- **RPC 死锁**：退出回调曾经持锁调用取错误信息的函数，Pi 一旦自己崩溃，整个客户端连同 `Stop` 会永久卡死。现在退出路径不再重入加锁，启动即退出也能直接报出原因。
- **Worker 池**：请求进行中的 Worker 不会再被当成空闲淘汰；关池时统一收集所有 Pi 客户端，不再留下孤儿进程。
- **会话历史缓存**：同时按 24 条与 256 MB 限制，淘汰按最近使用时间（原来遍历 map 随机丢）；增量读取改 `io.ReadFull`，大块追加时不再漏掉后半截消息。
- **写文件**：非 Windows 覆盖时保留原文件权限；Windows 改成「原文件先改名 `.bak` 再替换、失败就恢复」，不再先删原文件导致新旧两头落空。
- **文件监听**：`unwatch` 真的释放 fsnotify 句柄；新建子目录的监听登记到所属 root，不再刚加上就被移除。
- **终端 / worktree / 子进程**：终端启动全程持锁避免并发超限；worktree 合并结束后切回原分支；`git clone` 失败只删本次新建的目录；子进程设 `WaitDelay`，Windows 先 `taskkill /T /F`；网络类 git 命令超时放宽到 30 分钟；`NO_PROXY` 保留用户配置并并入 localhost / 127.0.0.1 / ::1。

## 工程

- Go 源码统一 LF（`.gitattributes`），Windows 上 `gofmt -l` 不再列满整包。
- CI：actions 固定到 commit SHA；Linux 加跑 `go test -race ./internal/host`；构建前注入签名公钥，发布时为校验清单生成 `.sig`。

## 校验

```bash
npm run check                # 62 项前端检查 + go test ./...
go test -race ./internal/host
npm audit && npm audit --prefix packages/ui
npx mygo build
PI_DESKTOP_SMOKE=1 PI_DESKTOP_SMOKE_PTY=1 PI_DESKTOP_SMOKE_BASH=1 PI_DESKTOP_SMOKE_PROMPT=1 PI_DESKTOP_SMOKE_UI=1 PI_DESKTOP_SMOKE_SETTINGS=1 PI_DESKTOP_SMOKE_REPO=1 npx mygo dev
```

## 已知限制

- **自动更新需要手动升级一次**（见上）。换签名密钥同理：老客户端会拒装，需要再手动升级一次。
- 本地自行编译的版本没有内置公钥，点「下载更新」会提示只能手动下载 —— 这是预期行为，正式产物由 CI 注入。
- 远程图片关掉自动加载后只显示占位，需要逐张点开。
