# Pi Desktop v0.9.0

**换内核了：从 Electron 换到 MyGo（Go 宿主 + 系统 WebView），界面和用法不变。**

安装包从 **120 MB 降到 7.3 MB**，冷启动到窗口出现约 **0.37 秒**。代价是 Windows 依赖系统的 WebView2、Linux 依赖 WebKitGTK（不再自带 Chromium）。

## 为什么要换

| | 0.8.x（Electron） | 0.9.0（MyGo） |
|---|---|---|
| Windows 安装包 | 120.5 MB | **7.3 MB** |
| 可执行文件 | 约 230 MB 解包目录（含 Chromium） | **35 MB 单 exe** |
| 冷启动到窗口 | 秒级 | **约 0.37 秒**（本机实测） |
| 主进程 | TypeScript + IPC + preload | **Go**（`internal/host`） |
| 终端 | `node-pty` 原生模块（按 Electron ABI 重编译） | **Go ConPTY / Unix PTY** |
| 原生依赖 | 需要 C++ 工具链 | 纯 Go，可交叉编译 |

内存方面**没有明显变化**：系统 WebView2 同样是多进程，实测总和与旧版相当（约 500 MB 量级）。这一版的收益是安装包体积、启动速度、构建链路简化，而不是内存。

## 功能上有什么变化

界面与交互基本保持原样，宿主能力全部在 Go 里重写：

- 会话（RPC 宿主池、分页历史、崩溃重连、超时重试）、模型与思考等级、工具开关、MCP、技能 / 扩展 / 包、项目信任、代理与更新检查、日志、单实例锁。
- 文件读写与磁盘变化监听（`fsnotify`）、Git 面板与隔离工作区（Worktree）、终端（多标签、shell 配置、Ctrl+C / 回显 / resize）、拖放路径、无边框窗口拖动。
- 新增一层**液态玻璃**视觉：侧栏 / 主区 / 编辑器 / 面板各自成为带镜面高光与柔和阴影的圆角玻璃岛屿，间隙露出 Kero 风格的渐变窗框；新增 wash 主题（可浅色 / 深色分别设置），标题栏左上角改为 Pi 字标。

## 升级须知（重要）

1. **0.8.x 的自动更新不会跨到 0.9.0**：产物类型完全不同，请手动下载本页的安装包覆盖安装。
2. **界面设置需要重新配置一次**：桌面端设置（主题、默认模型、输入框偏好、最近文件等）存在 WebView 的存储里，换引擎后是一个新的存储目录。会话、项目、工作区、Git 都在磁盘上，不受影响。
3. **Windows 10 需要 WebView2 Runtime**（Windows 11 自带；也可从微软官网安装）。缺少时启动会提示。
4. macOS 需要 13+，Linux 需要 WebKitGTK 4.1（`libwebkit2gtk-4.1-0`）。
5. Pi 仍然用你本机安装的那一份（`pi --mode rpc`），桌面端不内置推理与工具执行：`pi` 和它需要的运行时由你自己安装和升级。

## 已知限制

- 首次启动会比之后慢一点（WebView2 初始化）。
- 0.9.0 的桌面端自动更新使用 GitHub Release 资产 + SHA256 校验；暂时没有做增量更新。
