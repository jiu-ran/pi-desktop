# Pi Desktop v0.8.8

三处修正，都跟「界面别撒谎」有关：跨版本残留的空目录、重开应用后不肯消失的红卡、以及说不清严重程度的断网提示。

## 断网提示说清楚「试了几次、接下来做什么」

- 彻底失败时不再只剩「网络连接失败 ×2」：
  - 标题写次数 → `网络连接失败 · 重试 3 次仍未成功`
  - 副标题给下一步 → `检查网络或代理后再发一次`（灰字，红色只留给失败本身）
- 次数已经在标题里，就不再单独显示 `×N` 徽标。
- 连上之后仍然就地变绿：`✓ 已重新连接，任务继续`，副标题一起收掉。

## 重开应用后不再挂着过期的断网红卡

回放历史（打开会话 / 重启应用 / 切换会话）以前只把 `stopReason === "error"` 的消息变成红卡，**从不检查后面是否已经成功**；而实时路径是会刷成「已重新连接」的。于是同一次断网：实时看是绿的，重开应用就成了永不消失的红卡。

现在回放也认「后来连上了」，「中断（aborted）」不算恢复。

## 隔离工作区移除后的空壳不会再被当成「新项目」

移除隔离工作区时若目录被占用，可能只留下一个空目录（没有 `.git`）。它仍留在「最近项目」里，点进去版本控制面板会显示「当前项目还不是 Git 仓库」+「初始化 Git 仓库」—— 在托管目录里初始化只会多出一个嵌套仓库。

- 面板现在识别这种目录：显示「这个目录已不是有效的工作区」+「从最近项目移除」，不再给初始化按钮。
- 启动维护会清掉 `<用户数据>/worktrees` 下的**空**目录（真工作区至少有 `.git` 文件，不可能为空），有内容一律跳过。

## 文件树里就地新建（仿 VS Code）

- 新建文件 / 新建文件夹不再弹对话框：直接在目标目录里长出一行输入框。
- **Enter** 创建、**Esc** 取消、点别处有名字就提交（空着当取消）。
- 右键文件夹「新建文件 / 新建文件夹」会自动展开那个目录，输入框就在子层级缩进里；工具栏也补了「新建文件夹」按钮。
- 名字不合法（含斜杠、Windows 保留字符、`.` / `..`、超长）就地提示一句，不打断输入；空的按取消处理。

## 已知限制

- macOS 安装包未签名 / 未公证，首次打开需要在「系统设置 → 隐私与安全性」放行；Windows 未做代码签名，SmartScreen 可能提示未知发布者。
- Linux 的 `AppImage` 需要 `libfuse2`；没有 FUSE 的环境请用 `tar.gz`。
- 本机需要有能运行的 `pi`；桌面端不内置 Pi 的副本。
- `/tree`、`/login`、`/share` 这类依赖 Pi 交互模式的功能只能在终端里用（`/` 菜单里不列出，敲出来会给说明）；`/llama` 目前会当普通文字发给模型（待修）。
- 出网方式只作用于应用自身与 Pi 子进程；内置终端里的命令走你自己的 shell 环境。
- 终端依赖本机已装的 CLI 与 shell，应用不会代为安装、登录或配置。
- 文本文件读取 / 保存上限 20 MB，超过 2 MB 以只读大文件模式打开。
