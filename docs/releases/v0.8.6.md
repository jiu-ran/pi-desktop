# Pi Desktop v0.8.6

两条主线：**在对话里直接跑 shell 命令**，以及**设置里能开关 Pi 的内置工具**。

## 对话里直接跑命令（`!` / `!!`）

- 输入框里敲 `!` 切到 shell 模式：`!` / `!!` 只作为模式标记，不进入输入框（也可以先写好命令再把光标放到开头按 `!`）。
- 命令在**项目目录**里执行，输出**流式**显示在对话里，下一次提问时作为上下文交给模型。
- `!!` 同样执行，但输出只留在会话记录、**不进入模型上下文**。
- 运行中的卡片可以「停止」，也可以按 Esc 中断。
- 退出码非 0 标为失败；输出被截断时给出完整输出路径。

## 工具开关

- 设置 → 扩展 → **工具开关**：启用 / 停用 Pi 的内置工具（`read` / `bash` / `edit` / `write` / `grep` / `find` / `ls` / `powershell`）与 `codemode` / `tool_search`。
- 写入 Pi 的 `defaultTools`（**全局或当前项目**，沿用 Pi 的合并规则；项目级需要先信任项目）。终端里的 `pi` 也使用同一份选择。
- 桌面端启动 Pi 时用 `--tools +name/-name` 校正已有会话（Pi 1.3 起恢复会话会保留当时的工具）。
- MCP 工具不由这里控制，仍看 MCP 页的暴露模式。
- 开关在**下次启动 Pi 时生效**；设置页可一键重启空闲会话。

## 已知限制

- macOS 安装包未签名 / 未公证，首次打开需要在「系统设置 → 隐私与安全性」放行；Windows 未做代码签名，SmartScreen 可能提示未知发布者。
- Linux 的 `AppImage` 需要 `libfuse2`；没有 FUSE 的环境请用 `tar.gz`。
- 本机需要有能运行的 `pi`；桌面端不内置 Pi 的副本。
- `/tree`、`/login`、`/share` 这类依赖 Pi 交互模式的功能只能在终端里用（`/` 菜单里不列出，敲出来会给说明）。
- `/llama` 目前不在 `/` 菜单里，也不在「需要终端」的拦截表里 —— 敲出来会被当成普通文字发给模型（下个版本修）。
- 终端依赖本机已装的 CLI 与 shell，应用不会代为安装、登录或配置。
- 文本文件读取 / 保存上限 20 MB，超过 2 MB 以只读大文件模式打开。

发布产物附 `SHA256SUMS.txt`，覆盖三个平台的全部安装包。
