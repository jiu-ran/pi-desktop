# Pi Desktop v0.6.0

这一版有两件新东西：标题栏的「打开」按钮变成菜单，多出「从 Git 克隆」——填个地址就能把仓库拉下来并直接打开；以及渲染进程崩溃后不再停在黑屏，会自动重载，反复崩就退到软件渲染。另外对话搜索收敛到正文、`Ctrl+F` 终于能直接把光标放进搜索框，初始页整页重做，最大化也真正四边贴满了。

## 从 Git 克隆

- **入口**：标题栏「打开」按钮现在是菜单，两项——「打开文件夹…（Ctrl+O）」和「从 Git 克隆…」；欢迎页也放了一个二级按钮。
- **弹窗**：填仓库地址、选克隆到哪个位置（复用系统的文件夹选择器），下方实时显示「将克隆到 `…`」，不用先猜目录名。仓库地址没填时「克隆」是禁用的，克隆过程中按钮显示「正在克隆…」且不允许关窗，失败就把 git 的报错原文显示出来。
- **目录名怎么来的**：从地址里推导——`https://host/owner/repo.git`、`git@host:owner/repo`、`ssh://git@host:端口/owner/repo.git`、`file:///…`、Windows 本地路径、带查询串、末尾带斜杠都能认；推导逻辑是纯函数，界面预览和主进程复核用的是同一套。
- **安全边界**：只接受绝对路径；父目录必须存在；目标不存在或必须是空目录；拒绝 `-` 开头的地址（会被 git 当成选项）与含控制字符的地址；克隆时关掉交互式凭据提示（`GIT_TERMINAL_PROMPT=0`），需要登录的仓库会直接报错而不是无限等待。

## 崩溃不再等于黑屏

- **自动重载**：渲染进程崩了，800ms 后自动重载页面，窗口自己回来。
- **崩溃循环兜底**：一分钟内连崩三次，改用原生对话框问「重新加载界面 / 退出」——原生对话框不依赖渲染进程，黑屏时照样能用。
- **下次启动自救**：崩溃记录会跨启动保存（只留 24 小时 / 最近 20 条）。24 小时内崩到 3 次，下次启动自动关闭硬件加速，用软件渲染先把界面跑起来。
- **排查材料**：崩溃时把 Browser / GPU / Utility 各进程的内存写进 `logs/app.log`（OOM 一眼可见），并在本地留 minidump（**不上传**）。手动关硬件加速：`PI_DESKTOP_DISABLE_GPU=1`。

## 搜索与焦点

- **只搜正文**：以前搜索会把思考过程、工具参数、工具输出、提示块一起算命中，计数一下刷到几十条，反而找不到目标句子。现在只匹配用户消息和助手正文。
- **流式中不计数**：还在输出的消息不参与命中统计，避免数字和位置一直跳。
- **`Ctrl+F` 直接可用**：搜索条和滚动区是兄弟节点，之前那段「在滚动区的父节点里找输入框」的代码永远拿到 `null`，所以按了 `Ctrl+F` 光标没进去。现在焦点和全选都会落到位，`Esc` 关闭后焦点还给输入框。

## 初始页

- **整页垂直居中**：之前 `.welcome` 是 flex 列的子项但没写 `flex: 1`，高度跟着内容走，所以内容贴顶、下面空一大片。
- **版本号改成徽标**，能力说明改成带图标的胶囊（终端只在插件启用时出现），四个入口提示拆成独立条目、窄窗口也能正常换行。
- **对比度**：次级文字从 `--fg-3` 提到 `--fg-2`，浅色主题下 2.7:1 → 5.2:1。

## 窗口最大化

之前底部总有一条细白线：那是原生最大化比屏幕矮 1 DIP 露出来的桌面（实测客户区 1536×863、屏幕 1536×864）。现在放大动画仍然交给系统，动画结束后（约 260ms）切一次全屏把这条缝补掉——全屏客户区正好等于屏幕，不画圆角、内容也不位移，所以前后只差 1 DIP，看不到跳变。还原依旧回到原来的位置和尺寸。

## 其它修复

- **快速打开（`Ctrl+P`）丢样式**：重写设置面板时把 `components.css` 末尾的通用浮层区块整段删掉了，输入框退回浏览器原生外观。已按重写前的定义补回，并加了静态断言与冒烟步骤两道守门。
- **侧栏空状态**：没打开项目时那块「还没有任务」的占位删掉，直接留白。
- **模型选择器**：去掉前面那枚立方体图标。

## 已知限制

- macOS 安装包未签名 / 未公证，首次打开需要在「系统设置 → 隐私与安全性」放行；Windows 未做代码签名，SmartScreen 可能提示未知发布者。
- Linux 的 `AppImage` 需要 `libfuse2`；没有 FUSE 的环境请用 `tar.gz`。
- 终端依赖本机已装的 CLI 与 shell，应用不会代为安装、登录或配置。
- 文本文件读取 / 保存上限 20 MB，超过 2 MB 以只读大文件模式打开。
- 「从 Git 克隆」不会代为处理凭据：需要登录的仓库请先在系统里配好凭据助手或 SSH key。
