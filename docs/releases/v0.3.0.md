# Pi Desktop v0.3.0

设置里的「外观与布局」重做：新增配色模式、强调色、圆角、对话列宽、关闭动效，加了实时预览和「恢复默认外观」，其余外观项统一成分段控件。

## 新增外观选项

| 选项 | 取值 | 作用位置 |
| --- | --- | --- |
| **配色模式** | 跟随系统 / 深色 / 浅色 | 整个界面；跟随系统时随系统深色偏好实时切换 |
| **强调色** | 默认蓝、紫罗兰、青碧、松绿、琥珀、玫瑰、石墨 | 按钮、选中态、链接、高亮块（`--accent` / `--accent-soft`） |
| **圆角** | 直角 4px / 标准 8px / 圆润 12px | 卡片、输入框、弹层、消息气泡 |
| **对话列宽** | 窄 620 / 标准 760 / 宽 980 / 铺满 | 消息正文与输入框的最大宽度 |
| **关闭界面动效** | 开 / 关 | 弹层过渡、加载动画、平滑滚动 |

原来的界面字号、代码字号、消息密度、界面缩放也改成同款分段控件，和新增项放在一张「排版」卡里。

## 界面

- 「主题」「排版」「动效」「工作区面板布局宽度」四张卡分组，外观项集中在前三张。
- **实时预览**：用户气泡、强调色标签、代码、工具卡片各一份；改任何一项都即时生效（预览块和主界面共享同一套 CSS 变量）。
- 右上角「恢复默认外观」只还原外观相关项（主题/强调色/圆角/列宽/动效/字号/密度/缩放），不会动终端、Agent、MCP 等设置。
- 主题卡带缩略图（跟随系统是左右分色），强调色是色板圆点，当前项有描边高亮。

## 实现要点

- 纯函数模块 `shared/appearance.ts`：预设表 + 取值归一化 + CSS 变量推导（`appearanceStyle` / `accentVars` / `radiusVars` / `columnWidthVars` / `resolveScheme`）。
- 老配置迁移：以前只存 `pi-desktop.theme`（dark/light），没有 `themeMode`。升级后按当时的配色锁定成「深色/浅色」，不会突然变成跟随系统。
- 标题栏的主题按钮等同于「锁定深色/浅色」，会把配色模式一起改掉，避免和外观 watcher 互相覆盖。
- 「跟随系统」同时监听 `matchMedia` 的 `change` 事件，并有 1.5s 兜底轮询 —— 个别环境（CDP 模拟、部分 Linux 桌面）`change` 不触发。
- 对话列宽通过 `--chat-column` 注入，`--column` 回落到原来的 760px；动效开关落到 `<html data-motion="off">`。

## 校验

- `appearance.check.ts`：取值归一化（拼错的 `systemm`、非法颜色一律回默认）、预设 id 唯一、`withAlpha` 只接受 6 位十六进制、深浅色淡底不同、圆角/列宽变量、`appearanceStyle` 的变量与 data 属性、`resolveScheme` 四种组合。
- `appearance.electron.mjs`（已接入冒烟）：
  - 控件齐备：3 张主题卡、7 个色板、≥15 个分段、预览块、恢复默认按钮
  - 点「紫罗兰」→ `--accent` 变 `#8b5cf6`、`--accent-soft` 变 `rgba(139, 92, 246, …)`、`data-accent` 同步、写入 localStorage
  - 点「圆润」→ `--radius: 12px` / `--radius-sm: 9px`；点「铺满」→ `--chat-column: 100%`
  - 关动效 → `data-motion="off"` 且过渡时长归零
  - 切「浅色」→ `data-theme="light"`；「跟随系统」+ CDP 模拟系统深/浅色 → 界面跟着切
  - 「恢复默认外观」→ 外观项回默认，`sendShortcut`/`autoSave`/`terminalProfile` 等其它设置原样保留
- `npm run check` 全绿；Electron 冒烟 13 步全 PASS。
